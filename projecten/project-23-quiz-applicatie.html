Project 23: Quiz Applicatie

Master

Bouw een interactieve quiz met statemanagement, voortgangsgrafieken en directe feedback.

📚 Wat ga je leren?

  • Interactieve quiz-states beheren (huidige vraag, score).
  • Dynamisch DOM-elementen genereren (antwoordenlijst).
  • CSS-animaties aansturen via JavaScript-timers (ronde voortgangscirkel).

🎯 Belangrijke Concepten

  • Array van Objecten - Datastructuur voor de vragen.
  • State Management - Bijhouden van variabelen zoals score en currentQuestion.
  • setInterval() - Gebruikt voor het animeren van het taartdiagram (de scorecirkel) aan het einde van de quiz.

📝 Stap-voor-Stap Uitleg

Stap 1: Variabelen en Vragen instellen

We gebruiken state-variabelen om te onthouden waar we zijn in de quiz.

let currentQuestion = 0;
let score = 0;
let canAnswer = true;

Stap 2: Vraag inladen

Maak de container leeg en vul deze met de nieuwe vraag en de antwoordknoppen.

optionsContainer.innerHTML = '';
q.options.forEach((opt, index) => {
    const div = document.createElement('div');
    div.innerHTML = opt;
    optionsContainer.appendChild(div);
});

Stap 3: Antwoord controleren

Controleer de gekozen index met het juiste antwoord en update de CSS-klassen (rood/groen).

const isCorrect = (index === questions[currentQuestion].answer);
if (isCorrect) score++;

🛡️ Antwoord controleren (Anti-Spam)

function checkAnswer(optDiv, index) {
    if (!canAnswer) return; // Voorkomt 2x klikken op dezelfde vraag
    canAnswer = false;
    // Logica om knoppen rood/groen te kleuren
    nextBtn.style.display = 'block';
}

🚀 Jouw Opdracht:

  • Speel de quiz en bekijk hoe de DOM de vragen live bijwerkt.
  • Observeer hoe de canAnswer variabele voorkomt dat je dubbel kunt klikken op een antwoord.

💡 Tips & Tricks

  • Data vs. Weergave: Door alle data in één JavaScript-array te scheiden van de HTML, kun je de quiz later eenvoudig vanaf een externe bron (API) inladen.

⚠️ Veelvoorkomende Fouten

Fout: Hardcoded vragen in HTML

Bouw nooit 20 losse HTML-pagina's voor een quiz. Gebruik JavaScript om de tekst binnen dezelfde pagina telkens te vervangen, waardoor je applicatie schaalbaar blijft.

<!-- ❌ FOUT -->
<div class='vraag1'>Vraag 1...</div>
<div class='vraag2'>Vraag 2...</div>

// ✅ GOED
questionText.innerText = q.q;

🚀 Uitbreidingsmogelijkheden

  • Timer toevoegen: Voeg een automatische countdown-timer van 10 seconden toe per vraag.
  • Vragen husselen: Shuffle de antwoordopties willekeurig.

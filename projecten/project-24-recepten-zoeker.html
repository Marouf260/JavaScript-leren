Project 24: Recepten Zoeker

Master

Bouw een receptenzoekmachine met geavanceerde .filter() methoden in JavaScript.

📚 Wat ga je leren?

  • Gegevens ophalen via een externe bron via de Fetch-API
  • Werken met asynchrone functies (async/await)
  • JSON-data parseren en vertalen naar bruikbare HTML-componenten

🎯 Belangrijke Concepten

  • Fetch API - De moderne manier om data te halen vanaf een andere sever.
  • async / await - Pauzeert de uitvoering van een functie totdat de benodigde data gedownload is.
  • Template literals (``) - Grote stukken HTML overzichtelijk als een string in JavaScript injecteren.

📝 Stap-voor-Stap Uitleg

Stap 1: De Fetch Request opzetten

We gebruiken de Fetch-API om de receptendata als JSON op te halen.

const response = await fetch(`https://api.example.com/recipes?q=${query}`);
const data = await response.json();

Stap 2: Data weergeven in de browser

Doorloop de teruggestuurde recepten met forEach en toon ze dynamisch op het scherm.

resultsContainer.innerHTML = '';
data.recipes.forEach(recipe => {
    resultsContainer.innerHTML += `<div>${recipe.title}</div>`;
});

Stap 3: Fouten afvangen (Error Handling)

Als de aanvraag naar de server mislukt (bijvoorbeeld door een internetstoring), vangen we dit af met een try/catch-blok.

try {
    // fetch data
} catch(error) {
    console.log('Oeps, server fout', error);
}

💻 Volledige Zoekfunctie

async function searchRecipes() {
    const query = searchInput.value;
    if(!query) return;
    try {
        // Laad-animatie tonen
        loader.style.display = 'block';
        const res = await fetch('url' + query);
        const data = await res.json();
        renderData(data);
    } catch(err) {
        alert('Kon niet laden');
    }
}

✅ Jouw Opdracht:

  • Typ de naam van een gerecht in (bijv. "Pasta").
  • Zie hoe JavaScript asynchroon wacht op de data, en de HTML daarna dynamisch aanvult.

💡 Tips & Tricks

  • Debouncing: Om te voorkomen dat je bij elke toetsaanslag onnodig vaak een server aanroept, kun je met behulp van setTimeout een zogenaamde 'debounce' inbouwen.

⚠️ Veelvoorkomende Fouten

Fout: Vergeten async/await te gebruiken

Zonder await loopt JavaScript al verder voordat de server de data daadwerkelijk heeft teruggestuurd. We kunnen niet proberen iets in de HTML te plaatsen dat nog onderweg is.

// ❌ FOUT
const res = fetch('url');
console.log(res); // undefined of Promise (nog niet klaar)

// ✅ GOED
const res = await fetch('url');
console.log(await res.json()); // Correct

🚀 Uitbreidingsmogelijkheden

  • Favorieten opslaan: Gebruik LocalStorage om een lijst aan gekozen favoriete recepten blijvend op te slaan.
  • Filteropties toevoegen: Voeg een mogelijkheid toe om extra criteria te filteren, zoals uitsluitend 'Vegan'.

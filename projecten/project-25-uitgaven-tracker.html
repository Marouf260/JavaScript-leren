Project 25: Uitgaven Tracker

Master

Bouw een uitgebreide tracker die budget en uitgaven lokaal opslaat.

📚 Wat ga je leren?

  • Gegevens beheren en berekeningen uitvoeren met JavaScript-arrays.
  • Financiële getallen formatteren voor een herkenbare weergave in valuta.
  • Totalen in real-time herberekenen en direct updaten in de weergave.

🎯 Belangrijke Concepten

  • map() / reduce() / filter() - Onmisbare array-methoden om berekeningen te doen zoals totalen bepalen en inkomsten van uitgaven scheiden.
  • DOM Events koppelen - Genereer en verwijder dynamisch items uit de lijst bij interactie met knoppen.

📝 Stap-voor-Stap Uitleg

Stap 1: Totaal berekenen met Reduce

De totale balans (of globale uitgaven) rekenen we beknopt uit door alle afzonderlijke bedragen op te tellen via reduce().

const total = transactions
    .map(t => t.amount)
    .reduce((acc, current) => acc + current, 0);

Stap 2: Kosten splitsen met Filter

Je kunt `filter()` gebruiken om enkel de inkomsten (positieve getallen) of uitsluitend de uitgaven (negatieve getallen) over te houden in een nieuwe array.

const income = amounts
    .filter(item => item > 0)
    .reduce((acc, item) => (acc += item), 0);

Stap 3: Lijst weergeven in de browser

Genereer voor elke geregistreerde transactie een lijst-item. Let op het toevoegen van een dynamische CSS-class ('plus' of 'minus').

const item = document.createElement('li');
item.classList.add(transaction.amount < 0 ? 'minus' : 'plus');

✅ Jouw Opdracht:

  • Voeg inkomsten en de bijbehorende uitschrijvingen uit op het webformulier.
  • Hanteer het kruisje of verwijderknop om een reeds aangemaakte inkomst ongedaan the maken. Zie hoe de visuele balans zichzelf aanpast.

💡 Tips & Tricks

  • Unieke IDs genereren: Gebruik `Math.floor(Math.random() * 100000000)` of `Date.now()` voor een volstrekt uniek ID voor elke opgeslagen regel.

⚠️ Veelvoorkomende Fouten

Fout: Types door elkaar husselen

Zelfs een numeriek formulierveld levert vaak het type tekst terug in pure JavaScript-logica. Hierdoor creëert men weleens ongebruikelijke string concatenatie ("10" + 20) in de plaats van een mathematische rekensom (30).

let bedrag = input.value; // '10'
let totaal = totaal + bedrag; // Resultaat: '10010' in plaats van 110

let bedrag = parseFloat(input.value); // of +input.value

🚀 Uitbreidingsmogelijkheden

  • LocalStorage Integreren: Bouw een diepere implementatie in zodat het de gecreëerde data opvangt en terug ophaalt wanneer jij the venster zou refreshen.
  • Grafisch Cirkeldiagram: Visualiseer de verhouding tussen inkomsten en uitgaven in een taart weergave.

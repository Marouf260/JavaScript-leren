Project 26: Muziek Speler

Master

Bouw een muziekspeler met draaiende platen covers, een voortgangsbalk en play/pauze commando's.

📚 Wat ga je leren?

  • De native HTML5 Audio API integreren met JavaScript.
  • Afspeelbalken (progress bars) vloeiend binden aan de werkelijke speel-tijd.
  • CSS-animaties slim pauzeren en laten meebewegen op basis van JavaScript functionaliteiten.

🎯 Belangrijke Concepten

  • audio.play() / pause() - De ingebouwde JavaScript-methodes om media af te laten spelen vanuit de browser.
  • timeupdate Event - Een speciaal media event dat hoogfrequent activeert in de browser als de muziek loopt; onmisbaar voor het tekenen van laadbalken.
  • Class toggles - Het switchen van the Play / Pause icoon door styling-classes heen en weer te verplaatsen.

📝 Stap-voor-Stap Uitleg

Stap 1: Functionaliteiten koppelen aan de controller

Een opgeslagen <audio> element kun je in Javascript bereiken en manipuleren met de `play()` of `pause()` API.

const audio = document.getElementById('audio');
function playSong() {
    musicContainer.classList.add('play');
    audio.play();
}

Stap 2: Tijd en voortgangsbalk bijwerken

Door telkens rekensommen toe te passen tussen de verstreken speelduur en de bestandsgrootte kunnen we een breedte (width) in percent (%) vormen voor de balk.

function updateProgress(e) {
    const { duration, currentTime } = e.srcElement;
    const progressPercent = (currentTime / duration) * 100;
    progress.style.width = `${progressPercent}%`;
}

Stap 3: Navigeren door de tracks

Om vloeiend nummers over te slaan springen we door een opgevraagde Data-Array d.m.v. incrementele waardes als `songIndex++`.

function nextSong() {
    songIndex++;
    if(songIndex > songs.length - 1) {
        songIndex = 0;
    }
    loadSong(songs[songIndex]);
    playSong();
}

💻 Vrij klikken op de voortgangsbalk

function setProgress(e) {
    const width = this.clientWidth;
    const clickX = e.offsetX;
    const duration = audio.duration;

    audio.currentTime = (clickX / width) * duration;
}

✅ Jouw Opdracht:

  • Gebruik de actieve interface knoppen om tracks op te starten en over te hevelen naar andere tunes.
  • Klik willekeurig ergens in de breedte van de witte trackline; neem waar hoe JavaScript feilloos door de audiosporen heen reist.

💡 Tips & Tricks

  • Automatisch doorgaan: Maak het net zoals Spotify en plak een audio.addEventListener('ended', nextSong) achterin de file zodat je de handen niet vuilmaakt aan next-buttons drukken.

⚠️ Veelvoorkomende Fouten

Fout: Verdwalen in de the 'this' the context

Omdat we `.clientWidth` vereist achten binnen ons eigen custom Event, verifiëren moderne developers te dikwijls op basis van Arrow Functions (() =>) wat ten koste kan gaan de verlangde reference binnen ons specifiek domein. Houd dus je hoofd hier koel op. 

progressContainer.addEventListener('click', (e) => {
   // Binnen array syntax veranderen scope en is 'this' zojuist global-window geworden!
});

progressContainer.addEventListener('click', function(e) {
   // Zonder 'arrow' the method referentie grijpt 'this' het progressContainer-element feilloos aan.
});

🚀 Uitbreidingsmogelijkheden

  • Integreer een volumeknop: Gebruik een `input range`-element binnen in de controls list te om the volume op the `audio`-component van waarde in the schalen.
  • Afspeellijst presentie: Laat niet the enkel de titels opduiken bij wisselingen, bouw eventueel in dat het de gehele HTML side-bar index aftekent.

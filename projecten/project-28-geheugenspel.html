Project 28: 3D Geheugenspel

Master

Test je Javascript en CSS vaardigheden door een interactief geheugenspel met 3D animaties te bouwen.

📚 Wat ga je leren?

  • DOM-elementen genereren en deze indrukwekkend in het 3D-vlak roteren met CSS-transformaties.
  • Ingewikkelde spel-logica voor het vergelijken van de klikgeschiedenis programmeren.
  • Timers integreren (setTimeout) om animaties vloeiend de tijd te geven voordat het spel de status updatet.

🎯 Belangrijke Concepten

  • CSS 3D Transforms - Door JavaScript toegekende classes triggeren krachtige CSS-waarden zoals transform: rotateY(180deg);.
  • Data Attributes - Waardes zoals data-name='vuur' in de HTML steken om dit later aan de achterkant eenvoudig uit te lezen via dataset.icon.
  • SetTimeout() - Bouwt een kleine pauze in, waardoor de speler duidelijk ziet welke fout hij heeft gemaakt voordat kaarten terugdraaien.

📝 Stap-voor-Stap Uitleg

Stap 1: Kaarten Genereren

We itereren over een array met symbolen of emoji's en bouwen hiermee dynamisch het bord op.

cardsArray.forEach(item => {
    const card = document.createElement('div');
    card.classList.add('card');
    card.dataset.name = item.name;
    grid.appendChild(card);
});

Stap 2: Flip de Kaart (Event Listener)

Zodra je op een kaart klikt, wijst JavaScript de CSS-class .flip toe, wat meteen een 3D-animatie start.

card.addEventListener('click', function() {
    if (this === firstCard) return;
    this.classList.add('flip');
});

Stap 3: Kaarten Matchen

De dataset.icon bewaarde waardes van de geselecteerde kaarten worden afgewogen. Bij verlies wachten we exact één seconde en draaien we de speelkaarten via een reset-functie terug.

if (firstCard.dataset.name === secondCard.dataset.name) {
    disableCards();
} else {
    setTimeout(() => unflipCards(), 1000);
}

💻 Volledige Match-functie

function checkForMatch() {
    let isMatch = firstCard.dataset.name === secondCard.dataset.name;
    
    if (isMatch) {
        disableCards(); // Laat ze open staan
        matches++;
        if(matches === cardsArray.length) alert('Je hebt gewonnen!');
    } else {
        unflipCards(); // Draai ze opgelost terug
    }
}

function unflipCards() {
    lockBoard = true;
    setTimeout(() => {
        firstCard.classList.remove('flip');
        secondCard.classList.remove('flip');
        resetBoard();
    }, 1000);
}

✅ Jouw Opdracht:

  • Klik steeds op twee kaarten om deze tijdelijk te openbaren en ontdek alle aanwezige paren in je deck.
  • Bij het inkijken van de code zie je dat lockBoard garandeert dat de flow niet crasht als iemand supersnel probeert om op een derde kaart in te klikken terwijle de foutieve twee nog aan het wegdraaien zijn.

💡 Tips & Tricks

  • Betere Shuffle Functie (Fisher-Yates Methodiek): Onze gameGrid.sort(() => 0.5 - Math.random()); werkt vrij rudimentair. Leer jezelf de wiskundige 'Fisher-Yates'-methode aan en de willekeurigheid van het dooreengooien bereikt meester niveau!

⚠️ Veelvoorkomende Fouten

Fout: Dubbelklikken op dezelfde speelkaart toestaan

Door met hoge muisgevoeligheid dubbel de muistoets in te drukken, zou dezelfde aangeklikte speelkaart weleens de gehele controle flow (firstCard === secondCard) succesvol kunnen passeren, wat een direct gewonnen (scheef) resultaat zou opbouwen. Vang deze identieke DOM element triggers direct de pas af in je JS logic.

// ❌ FOUT
front.classList.add('flip');
checkForMatch();

// ✅ GOED
if (this === firstCard) return; // Voorkom dubbelklik!

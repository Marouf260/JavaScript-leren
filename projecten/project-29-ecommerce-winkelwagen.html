Project 29: E-commerce Winkelwagen

Master

Bouw een volledig uitgeruste webshop karretje met Drag-and-Drop functionaliteit!

📚 Wat ga je leren?

  • Complexe Object-Arrays muteren (items toevoegen, aantallen verhogen of items verwijderen).
  • Het dynamisch renderen van een winkelwagen-interface en de achterliggende logica.
  • Wiskundige berekeningen toepassen voor totalen en BTW in JavaScript.

🎯 Belangrijke Concepten

  • Array.find() / Array.map() - Perfect om te controleren of een specifiek product al in de mand zit voordat je het toevoegt.
  • Event Delegation - Luisteren op de bovenliggende container in plaats van op elke individuele 'verwijder' knop, wat de performance aanzienlijk verbetert.
  • Drag and Drop API - Gebruik maken van browser-native events om producten letterlijk de winkelwagen in te slepen.

📝 Stap-voor-Stap Uitleg

Stap 1: Item Toevoegen

We controleren eerst of het product al in de cart array aanwezig is. Zo ja, dan verhogen we de quantity. Zo nee, dan pushen we een nieuw object naar de array.

const existingItem = cart.find(item => item.id === productId);
if (existingItem) {
    existingItem.quantity++;
} else {
    cart.push({ id, name, price, quantity: 1 });
}

Stap 2: HTML Renderen via Templates

Loop door de actieve items in de winkelwagen en bouw een dynamische HTML-string die de actuele status van de mand weerspiegelt.

cart.forEach(item => {
    cartHTML += `
    <div>${item.name} - ${item.quantity}x</div>`;
});
cartDiv.innerHTML = cartHTML;

Stap 3: Totalen Berekenen

Gebruik de .reduce() methode om de prijs van elk item te vermenigvuldigen met de hoeveelheid en zo het totaalbedrag te berekenen.

const total = cart.reduce((temp, item) => {
    return temp + (item.price * item.quantity);
}, 0);

💻 Winkelmand State beheer

function updateCart(action, productId) {
    const item = cart.find(i => i.id === productId);
    if (action === 'ADD') item.quantity++;
    if (action === 'REMOVE') item.quantity--;
    
    // Verwijder items als de hoeveelheid 0 wordt
    cart = cart.filter(i => i.quantity > 0);
    
    renderCartUI();
}

✅ Instructies:

  • Klik op 'Toevoegen' bij een product of sleep de productkaart direct naar de gestreepte winkelwagen-zone om items toe te voegen.
  • Observeer hoe het totaalbedrag en het aantal items in de winkelwagen-badge live worden bijgewerkt door JavaScript.

💡 Tips & Tricks

  • LocalStorage Integratie: Zorg dat de inhoud van de winkelwagen bewaard blijft na een pagina-refresh door de cart array op te slaan in de localStorage van de browser.
  • UX Verbetering: Voeg een kleine animatie toe aan het winkelwagen-icoon wanneer er een nieuw item wordt toegevoegd voor een betere visuele feedback.

⚠️ Veelvoorkomende Fouten

Fout: HTML verversen verbreekt Event Listeners

Als je de innerHTML van een container volledig overschrijft, gaan alle direct gekoppelde event listeners op de oude onderliggende elementen verloren. Gebruik daarom Event Delegation op de parent container.

cartDiv.innerHTML = '... nieuwe items ...'; 
// De oude knoppen bestaan niet meer, de listeners zijn weg!

// ✅ Oplossing: Luister op de container
cartDiv.addEventListener('click', e => {
   if(e.target.matches('.delete-btn')) { ... }
});

🚀 Uitbreidingsmogelijkheden

  • Kortingscodes: Voeg een inputveld toe waar gebruikers een code kunnen invoeren (bijv. 'DOM20') voor 20% korting op het totaalbedrag.
  • Product Filters: Maak categorieën (Sieraden, Elektronica, etc.) en gebruik de .filter() methode om de lijst met getoonde producten dynamisch aan te passen.

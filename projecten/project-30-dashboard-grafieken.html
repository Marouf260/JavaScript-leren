Project 30: Data Dashboard

Master

Het summum. Verbind styling, CSS animaties en Javascript Data om een professioneel dashboard te genereren.

📚 Wat ga je leren?

  • Het converteren van complexe datasets en JSON-objecten naar visuele grafieken.
  • Het bouwen van interactieve data-widgets die de UI live updaten.
  • Werken met Chart-gerelateerde concepten zoals datapunten, labels en schaalverdelingen.

🎯 Belangrijke Concepten

  • Data Binding - Het koppelen van rauwe getallen aan visuele elementen zoals bar-heights of taartpunten.
  • CSS Container Queries - Zorgen dat grafieken zich optimaal aanpassen aan de beschikbare ruimte binnen het dashboard-grid.
  • Theme Syncing - Het overschakelen van kleuren en contrasten in JavaScript om de leesbaarheid van data consistent te houden in Dark Mode.

📝 Stap-voor-Stap Uitleg

Stap 1: HTML Structuur & Thema

Richt een dashboard-bord in met specifieke stat-kaarten. Elk element krijgt CSS-variabelen (zoals --dash-bg) zodat we met één druk op de knop het thema kunnen omzetten.

dashArea.classList.toggle('dark-theme');

Stap 2: Data schalen

Om een staafgrafiek correct weer te geven, berekenen we het percentage van de hoogte op basis van de maximale waarde in de dataset (Math.max).

const maxVal = Math.max(...chartData.map(d => d.value));
const heightPercent = (item.value / maxVal) * 100;

Stap 3: Dynamische Injectie

We creëren div elementen voor de balken en voegen daar gereedschappen zoals tooltips aan toe voor extra detail bij hover.

container.innerHTML = `
    <div class="bar-tooltip">${item.value}K</div>
    <div class="bar" style="height: 0%"></div>
`;

💻 Thema Switching Logica

themeBtn.addEventListener('click', () => {
    isDark = !isDark;
    const icon = isDark ? 'sun' : 'moon';
    dashArea.classList.toggle('dark-theme', isDark);
    themeBtn.innerHTML = `<i class="fas fa-${icon}"></i>`;
});

✅ Instructies:

  • Gebruik de thema-knop (het maantje) rechtsboven om te zien hoe de gehele layout en de grafiekkleuren zich aanpassen aan de donkere interface.
  • Beweeg je muis over de staven in de grafiek onderaan om de actuele verkoopcijfers in de tooltips te onthullen.

💡 Tips & Tricks

  • Live Data Updates: Om de grafiek te updaten zonder de pagina te herladen, kun je setTimeout of setInterval gebruiken die nieuwe waardes naar je rendering-functie stuurt voor een echt 'live effect'.
  • CSS-Only Charts: Voor simpele grafieken zoals deze heb je geen bibliotheek van 100KB nodig. Met HTML en slimme height berekeningen in flexbox bereik je vaak al een professioneel resultaat.

⚠️ Veelvoorkomende Fouten

Fout: Verkeerde schaalverdeling in grafieken

Als je de hoogste waarde in je dataset op 100 zet, maar je dataset bevat uitschieters (bijv. 500), dan zullen die letterlijk 'uit de grafiek vallen'. Bereken daarom altijd de relatieve hoogte op basis van het werkelijke maximum van de data.

// ✅ GOED - Dynamisch maximum bepalen
const max = Math.max(...data);
const height = (current / max) * 100;

🚀 Uitbreidingsmogelijkheden

  • Echte API Integratie: Vervang de statische chartData array door een fetch() aanroep naar een real-time crypto of weer-API om het dashboard écht tot leven te wekken.
  • Download Rapport: Voeg een knop toe die de huidige browser-view omzet in een PDF-bestand of afbeelding via bibliotheken zoals html2canvas.

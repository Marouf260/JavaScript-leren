Project 31: Parallax Scrolling

Advanced

Creëer een indrukwekkend diepte-effect waarbij de verschillende lagen van de pagina met verschillende snelheden scrollen.

📚 Wat ga je leren?

  • De scroll‑positie van een element of venster uitlezen met scrollTop en scrollY
  • Met transform: translateY() een achtergrond en voorgrond op verschillende snelheden laten bewegen
  • Een vloeiende parallax‑animatie maken zonder dat de pagina langzaam wordt

🎯 Belangrijke Concepten

  • scrollTop / scrollY – geven aan hoeveel er naar beneden is gescrold (in pixels)
  • Parallax effect – achtergrondlagen bewegen langzamer dan de inhoud ervoor waardoor diepte ontstaat
  • CSS transform – met translateY() schuif je elementen soepel omhoog of omlaag
  • requestAnimationFrame – manier om animaties performant te tekenen in plaats van alles direct in het scroll‑event te doen

📝 Stap-voor-stap uitleg

Stap 1: Scroll‑event gebruiken

Voeg een scroll‑listener toe op het element dat moet reageren (in dit voorbeeld de scrollbare container):

scrollArea.addEventListener('scroll', function() {
    const offset = scrollArea.scrollTop;
    // hier komt je animatielogica
});

Stap 2: Achtergrond langzamer laten bewegen

Gebruik de scroll‑waarde om de achtergrond minder snel te verplaatsen dan de inhoud:

pBg.style.transform = `translateY(${scrollPos * 0.5}px)`;

Uitleg: omdat we met 0.5 vermenigvuldigen, beweegt de achtergrond maar half zo snel als je scrolt.

Stap 3: Voorgrond‑boxen een eigen snelheid geven

Laat de tekstboxen met een andere factor meebewegen zodat er extra diepte ontstaat:

pBoxes.forEach((box, index) => {
    const speed = 0.1 * (index + 1);
    box.style.transform = `translateY(${scrollPos * speed}px)`;
});

Uitleg: elke box krijgt een iets andere snelheid; hoe hoger de index, hoe sterker de beweging.

💻 Scroll optimaliseren met requestAnimationFrame

let ticking = false;

window.addEventListener('scroll', function() {
  if (!ticking) {
    window.requestAnimationFrame(function() {
      let offset = window.scrollY;
      cloudLayer.style.transform = `translateY(${offset * -0.2}px)`;
      mountainLayer.style.transform = `translateY(${offset * 0.4}px)`;
      ticking = false;
    });
    ticking = true;
  }
});

✅ Instructies

  • Scroll in de demo‑container omlaag en omhoog om het parallax‑effect te zien.
  • Let op hoe de achtergrond langzamer beweegt dan de tekstboxen ervoor.
  • Experimenteer met de snelheidsfactoren in de JavaScript‑code om het effect aan te passen.

💡 Tips & Tricks

  • Beperk werk in het scroll‑event: gebruik requestAnimationFrame of een simpele vlag (zoals ticking) zodat je niet tientallen keren per seconde zware code draait.
  • Grote achtergronden: zorg dat de achtergrond hoger is dan het zichtbare gebied zodat je niet “uit” de afbeelding scrolt.

⚠️ Veelvoorkomende fouten

Fout: Achtergrond is te klein

Als je achtergrond maar 100vh hoog is, kun je er bij een sterk parallax‑effect “langs” scrollen en zie je een lege achtergrond.

/* Te klein voor sterk parallax-effect */
height: 100vh;

/* Beter: extra hoogte of combinatie met scale() */
min-height: 150vh;

🚀 Uitbreidingsmogelijkheden

  • Mousemove‑parallax: laat lagen reageren op de positie van de muis in plaats van scrollen.
  • Meerdere lagen: voeg extra voorgrond‑ en achtergrondlagen toe met elk hun eigen snelheid.

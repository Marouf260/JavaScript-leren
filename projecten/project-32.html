Project 32: Custom Video Player

Advanced

Bouw een professionele video player met een eigen interface en volledige controle over de afspeellogica.

📚 Wat ga je leren?

  • De Native HTML5 Video API in JavaScript gebruiken voor volledige mediacontrole.
  • Eigen custom UI elementen zoals play/pauze knoppen programmeren ter vervanging van de browser defaults.

🎯 Belangrijke Concepten

  • video.play() en video.pause() - Methoden om het standaard HTML video-element aan te sturen.
  • timeupdate - Een event dat continu afgaat tijdens het afspelen, essentieel voor het bijwerken van de progressie-balk.

📝 Stap-voor-Stap Uitleg

Stap 1: Play/Pause Toggle

Een simpele klik-actie die de status van de video omschakelt.

function togglePlay() {
    if (video.paused) {
        video.play();
        playBtn.innerText = 'Pause';
    } else {
        video.pause();
        playBtn.innerText = 'Play';
    }
}

Stap 2: De Progressie-balk Uitrekenen

Het percentage wordt berekend door de huidige tijd (current time) te delen door de totale tijdsduur (duration).

video.addEventListener('timeupdate', () => {
    const percent = (video.currentTime / video.duration) * 100;
    progressBar.style.width = `${percent}%`;
});

Stap 3: Afspeelsnelheid (PlaybackRate)

Je kunt de video sneller of langzamer laten afspelen door de playbackRate eigenschap te wijzigen.

speedBtn.addEventListener('click', () => {
    video.playbackRate = 1.5; // 1.5x de normale snelheid 
});

💻 Verspring 10 Seconden (Vooruit/Achteruit)

skipButtons.forEach(button => {
    button.addEventListener('click', function() {
        // Lees hoeveel we willen skippen uit het data-skip attribuut in de HTML
        const skipAmount = parseFloat(this.dataset.skip);
        // Tel dit op bij de huidige tijd van de video
        video.currentTime += skipAmount;
    });
});

✅ Instructies:

  • Speel de video af met de custom play knop of door direct op de video te klikken.
  • Gebruik de progress-bar om direct naar een specifiek moment in de video te springen.
  • Pas het volume aan met de slider en zie hoe de video-interface verbergt als je niet beweegt.

💡 Tips & Tricks

  • De paused property: In HTML5 Audio/Video is het altijd beter om de native boolean .paused te controleren voor de ware status, in plaats van zelf een variabele bij te houden.

⚠️ Veelvoorkomende Fouten

Fout: De 'Duration' is NaN

Als je de video.duration direct probeert op te vragen bij het laden, is de kans groot dat de browser de metadata van het bestand nog niet heeft gelezen. Dit resulteert in een NaN (Not a Number) fout.

console.log(video.duration); // NaN op regel 1

video.addEventListener('loadedmetadata', () => {
   console.log(video.duration); // Nu werkt het wel 
});

🚀 Uitbreidingsmogelijkheden

  • Fullscreen API: Integreer de element.requestFullscreen() methode om bioscoopervaring te bieden!
  • Volume Slider: Bouw een input type=range om het video.volume dynamisch te manipuleren.

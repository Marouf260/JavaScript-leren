Project 33: 3D Tilt Hover Kaarten

Advanced

Bouw premium 'Apple-style' 3D kaarten die naar je muis toe kantelen met een dynamisch lichteffect.

📚 Wat ga je leren?

  • Muis-events (clientX, clientY) omzetten naar 3D-rotaties in de DOM.
  • Het combineren van CSS perspective met JavaScript voor real-time diepte-effecten.

🎯 Belangrijke Concepten

  • getBoundingClientRect() – Bepaalt de exacte positie van een element op het scherm, nodig om de muispositie relatief aan de kaart te berekenen.
  • CSS Perspective – Creëert de 3D-ruimte waarin elementen kunnen 'kantelen' zonder dat ze er plat uitzien.
  • transform-style: preserve-3d – Zorgt ervoor dat kinderen van een element ook in 3D-ruimte blijven bestaan (nodig voor het parallax effect binnen de kaart).

📝 Stap-voor-Stap Uitleg

Stap 1: Muis-positie uitlezen

We luisteren naar het mousemove event op de kaart om de muispositie te tracken.

card.addEventListener('mousemove', (e) => {
    const rect = card.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;
});

Stap 2: Coördinaten Relativeren

De coördinaten worden berekend ten opzichte van het middelpunt van de kaart, zodat de rotatie vanuit het centrum gebeurt.

const centerX = rect.width / 2;
const centerY = rect.height / 2;
const rotateX = ((y - centerY) / centerY) * -15; // Max 15 graden
const rotateY = ((x - centerX) / centerX) * 15;

Stap 3: 3D Rotatie Toepassen

Pas de berekende graden toe op de transform property met een perspective waarde.

card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg)`;

💻 De Kaart Resetten (Mouse Leave)

card.addEventListener('mouseleave', () => {
    // Reset de rotatie naar 0 en voeg een transitie toe voor een zacht effect
    card.style.transition = 'all 0.5s ease';
    card.style.transform = 'perspective(1000px) rotateX(0deg) rotateY(0deg)';
});

✅ Instructies:

  • Beweeg je muis over de 3D-kaarten om het tilt-effect te zien.
  • Let op hoe de tekst en iconen 'bovenop' de kaart lijken te zweven dankzij translateZ.

💡 Tips & Tricks

  • Parallax Effect: Door elementen binnenin de kaart een transform: translateZ(50px) te geven, lijken ze echt zwevende lagen te zijn ten opzichte van de achtergrond.

⚠️ Veelvoorkomende Fouten

Fout: Muis-geflikker

Als iconen of tekst binnen de kaart het mousemove event 'stelen', kan de berekening verspringen. Gebruik pointer-events: none op kind-elementen of zorg dat je rect coördinaten altijd ten opzichte van de kaart berekent.

/* Oplossing in CSS */
.tilt-card * {
   pointer-events: none;
}

🚀 Uitbreidingsmogelijkheden

  • Glint/Shine Effect: Voeg een witte gradiënt laag toe die meebeweegt met de muis voor een echt glanzend oppervlakte effect.

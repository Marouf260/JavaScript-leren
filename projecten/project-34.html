Project 34: Multi-Step Formulier

Advanced

Maak een gebruiksvriendelijk formulier dat de input verdeelt over meerdere overzichtelijke stappen.

📚 Wat ga je leren?

  • State management in de UI: Het bijhouden van de huidige actieve stap (currentStep).
  • Het dynamisch tonen en verbergen van secties door middel van CSS classes en JavaScript.
  • Logische indeling van formulieren voor een betere gebruikerservaring.

🎯 Belangrijke Concepten

  • Event Prevention – e.preventDefault() voorkomt dat de browser de pagina ververst bij het verzenden van het formulier.
  • Validatie – Het controleren of alle velden in de huidige stap correct zijn ingevuld voordat we naar de volgende stap gaan.

📝 Stap-voor-Stap Uitleg

Stap 1: Stap-index Bijhouden

We gebruiken een variabele currentStep om bij te houden in welke sectie de gebruiker zich bevindt (0, 1 of 2).

let currentStep = 0;
const steps = document.querySelectorAll('.form-step');

Stap 2: Navigatie-logica

Bij een klik op 'Volgende' valideren we de input en verhogen we de currentStep index om de volgende sectie te tonen.

nextBtn.addEventListener('click', () => {
    // Validatie script hier
    steps[currentStep].classList.remove('active');
    currentStep++;
    steps[currentStep].classList.add('active');
    updateProgressUI();
});

Stap 3: Progress UI Updaten

De visuele indicators (de bolletjes bovenin) worden bijgewerkt op basis van de currentStep om de voortgang aan de gebruiker te tonen. 

progressDots.forEach((dot, index) => {
    if(index <= currentStep) {
        dot.classList.add('active');
    } else {
        dot.classList.remove('active');
    }
});

✅ Instructies:

  • Vul het formulier stap voor stap in.
  • Let op de validatie: je kunt niet doorgaan als verplichte velden leeg zijn (HTML5 validatie).

💡 Tips & Tricks

  • Live Validatie: Gebruik het input event op elk veld om direct te controleren of de invoer (zoals een e-mailadres) aan de eisen voldoet.

⚠️ Veelvoorkomende Fouten

Fout: Geen Validatie Check

Als je de stap verhoogt zonder te controleren of de huidige velden geldig zijn, kunnen gebruikers essentiële data overslaan.

nextBtn.addEventListener('click', () => {
  currentStep++; // ❌ Fout: We controleren niks!
});

nextBtn.addEventListener('click', () => {
   if(form.checkValidity()) {
      currentStep++;
   } else {
      showErrors();
   }
});

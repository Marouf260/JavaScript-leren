Project 35: Circular Progress Bars

Advanced

Creëer visueel aantrekkelijke, geanimeerde circulaire voortgangsbalken met behulp van SVG en JavaScript.

📚 Wat ga je leren?

  • SVG elementen en attributen manipuleren via JavaScript (voornamelijk stroke-dashoffset).
  • Het gebruik van wiskundige formules om de omtrek van een cirkel te bepalen voor animaties.
  • Data-attributen inzetten om target percentages dynamisch uit te lezen.

🎯 Belangrijke Concepten

  • SVG Cirkel Geometrie – Een cirkel heeft een totale lengte (omtrek) die we berekenen met 2 * π * radius.
  • Stroke Dashoffset – Bepaalt waar de 'lijn' van de cirkel begint. Door deze te veranderen, lijkt de cirkel 'vol' te lopen.
  • Stroke Dasharray – Definieert de lengte van de streepjes en de tussenruimte. We maken één groot streepje dat de hele cirkel beslaat.

📝 Stap-voor-Stap Uitleg

Stap 1: SVG Opzet

We maken een <svg> container met twee cirkels: één voor de achtergrond en één voor de gekleurde voortgangslijn.

<svg width='150' height='150'>
  <circle class='circle-bg' cx='75' cy='75' r='60'/>
  <circle class='circle-stroke' cx='75' cy='75' r='60'/>
</svg>

Stap 2: Omtrek Berekenen

In JavaScript berekenen we de omtrek van de cirkel om de juiste dasharray in te kunnen stellen.

const radius = circle.r.baseVal.value;
const circumference = 2 * Math.PI * radius;

circle.style.strokeDasharray = `${circumference} ${circumference}`;
circle.style.strokeDashoffset = circumference; // Start op 0%

Stap 3: Voortgang Updaten

Bereken de nieuwe offset op basis van het percentage en pas dit toe op de cirkel.

function setProgress(percent) {
    const offset = circumference - (percent / 100) * circumference;
    circle.style.strokeDashoffset = offset;
}

💻 De Percentage-teller Animeren

let currentVal = 0;
const target = 85;

const timer = setInterval(() => {
    if (currentVal >= target) {
        clearInterval(timer);
    } else {
        currentVal++;
        setProgress(currentVal);
        textElement.innerText = currentVal + '%';
    }
}, 20);

✅ Instructies:

  • Bekijk hoe de cirkels vloeiend vollopen bij het laden van de pagina.
  • Klik op de knop om willekeurige nieuwe data te genereren en de animaties te testen.

💡 Tips & Tricks

  • Responsive Circles: In een echte applicatie moet je de omtrek opnieuw berekenen als de container van grootte verandert (bijvoorbeeld via een ResizeObserver).

⚠️ Veelvoorkomende Fouten

Fout: Verkeerde Dasharray

Als de stroke-dasharray niet exact gelijk is aan de omtrek, zal het percentage dat getoond wordt niet overeenkomen met de visuele vulling van de cirkel.

/* Fout: Hardcoded waarde */
circle.style.strokeDasharray = '400 400';

/* Goed: Berekende waarde */
circle.style.strokeDasharray = `${circumference} ${circumference}`;

🚀 Uitbreidingsmogelijkheden

  • Intersection Observer: Start de animatie pas zodra de cirkels daadwerkelijk in beeld verschijnen tijdens het scrollen.

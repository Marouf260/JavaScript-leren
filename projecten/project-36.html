Project 36: Wachtwoord Sterkte Meter

Advanced

Maak een slimme tool die de sterkte van een wachtwoord live controleert met behulp van RegEx en visuele feedback.

📚 Wat ga je leren?

  • Het toepassen van Reguliere Expressies (RegEx) om patronen te herkennen in tekst.
  • Het bouwen van een real-time UI die direct reageert op input events.
  • Visuele feedback geven aan de gebruiker over de veiligheid van hun gegevens.

🎯 Belangrijke Concepten

  • RegEx Patterns – Gebruik maken van speciale syntax om te checken op cijfers (\d), hoofdletters ([A-Z]) en symbolen.
  • Dynamic Styling – Het aanpassen van CSS classes en stijlen op basis van de berekende veiligheidsscore.

📝 Stap-voor-Stap Uitleg

Stap 1: Input Event Luisteren

We luisteren naar elke toetsaanslag in het wachtwoordveld om de sterkte direct te kunnen berekenen. 

pwInput.addEventListener('input', (e) => {
    const pw = e.target.value;
    updateStrength(pw);
});

Stap 2: RegEx Checks

We gebruiken verschillende RegEx patronen om te controleren op getallen, hoofdletters en speciale tekens.

const hasNumber = /\d/.test(pw);
const hasUpper = /[A-Z]/.test(pw);
const hasSpecial = /[^A-Za-z0-9]/.test(pw);

Stap 3: Score Berekenen

Voor elke voldane eis verhogen we de score. Deze score bepaalt de kleur en breedte van de sterkte-meter.

let score = 0;
if (hasNumber) score++;
if (hasUpper) score++;
if (hasSpecial) score++;
if (pw.length >= 8) score++;

💻 UI Visueel Bijwerken

function updateMeter(score) {
    const width = (score / 4) * 100;
    meterBar.style.width = width + '%';
    
    if (score <= 1) {
        meterBar.style.backgroundColor = '#ef4444';
        strengthText.innerText = 'Zwak';
    } else if (score < 4) {
        meterBar.style.backgroundColor = '#f59e0b';
        strengthText.innerText = 'Gemiddeld';
    } else {
        meterBar.style.backgroundColor = '#10b981';
        strengthText.innerText = 'Sterk!';
    }
}

✅ Instructies:

  • Eexperimenteer met verschillende wachtwoorden en kijk hoe de meter reageert op cijfers, letters en symbolen.

💡 Tips & Tricks

  • RegEx Test Methode: Gebruik /pattern/.test(string) om snel te controleren of een string aan een patroon voldoet. Het geeft een simpele true of false terug.

⚠️ Veelvoorkomende Fouten

Fout: Wachtwoorden Opslaan in Memory

Sla wachtwoorden nooit op in globale variabelen of logs. Dit is een groot beveiligingsrisico.

/* ❌ NOOIT DOEN */
window.lastTypedPassword = pw;

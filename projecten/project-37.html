Project 37: Kanban Board (Trello-stijl)

Advanced

Bouw een professioneel Kanban-bord met de HTML5 Drag & Drop API om taken soepel te organiseren.

📚 Wat ga je leren?

  • Het gebruik van de Native Drag & Drop API van HTML5.
  • Elementen verplaatsen tussen verschillende containers in de DOM.
  • User interface feedback geven tijdens drag-and-drop acties.

🎯 Belangrijke Concepten

  • Draggable Attribuut – Een HTML-attribuut dat bepaalt of een element versleept kan worden door de browser.
  • Drag Events – JavaScript events zoals dragstart, dragover, en drop die de logica aansturen.
  • DataTransfer – Een object dat gebruikt wordt om data (zoals een ID) mee te geven tijdens de sleep-actie.

📝 Stap-voor-Stap Uitleg

Stap 1: Items Slepend Maken

Zet het attribuut draggable="true" op de elementen die je wilt kunnen verplaatsen.

<div class="task-card" draggable="true">Nieuwe Taak</div>

Stap 2: De Sleep-actie Starten

Wanneer het slepen begint, slaan we de ID van het element op in de dataTransfer.

card.addEventListener('dragstart', (e) => {
    e.dataTransfer.setData('text/plain', card.id);
    card.classList.add('dragging');
});

Stap 3: Loslaten (Pre-Drop)

Bij het loslaten halen we de ID weer op en voegen we het element toe aan de nieuwe kolom via appendChild. 

column.addEventListener('drop', (e) => {
    const id = e.dataTransfer.getData('text/plain');
    const element = document.getElementById(id);
    column.appendChild(element);
});

💻 Dragover Voorkomen

Standaard staat de browser drops niet toe. Je moet preventDefault() aanroepen op het dragover event om drops in te schakelen. 

column.addEventListener('dragover', (e) => {
    e.preventDefault(); // ESSENTIEEL
    column.classList.add('drag-over');
});

✅ Instructies:

  • Sleep een taak-kaart van de ene kolom naar de andere.
  • Gebruik de knop onderaan elke kolom om een nieuwe taak toe te voegen.

💡 Tips & Tricks

  • SetTimeout Hack: Gebruik setTimeout(() => card.style.display = 'none', 0) in de dragstart om het originele element op de pagina te verbergen terwijl je de 'ghost' afbeelding nog wel versleept.

⚠️ Veelvoorkomende Fouten

Fout: Vergeten e.preventDefault()

Als je verget e.preventDefault() aan te roepen in de dragover handler, zal de browser de drop event simpelweg weigeren af te vuren. 

/* FOUT: De drop werkt niet */
zone.addEventListener('dragover', (e) => {});

/* GOED: Browser staat drop toe */
zone.addEventListener('dragover', (e) => { e.preventDefault(); });

🚀 Uitbreidingsmogelijkheden

  • LocalStorage Integratie: Sla de positie van de kaarten op zodat ze na een refresh nog steeds in de juiste kolom staan.
  • Edit Functie: Maak het mogelijk om de tekst van een taak aan te passen na creatie.

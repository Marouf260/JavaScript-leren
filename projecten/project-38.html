Project 38: Toast Notificaties

Advanced

Vervang standaard browser alerts door een modern, geanimeerd en stapelbaar notificatiesysteem.

📚 Wat ga je leren?

  • Het dynamisch toevoegen en verwijderen van DOM-elementen.
  • Het gebruik van setTimeout om elementen na een bepaalde tijd te verwijderen.
  • CSS animaties aansturen via JavaScript voor vloeiende overgangen.

🎯 Belangrijke Concepten

  • appendChild() & remove() – De basisfuncties van de DOM om elementen in de boom te plaatsen of eruit te halen.
  • CSS Keyframes – Animaties die bepalen hoe een notificatie het scherm binnenkomt en verlaat.
  • Event Loop & Timers – Begrijpen hoe setTimeout werkt om notificaties op te ruimen.

📝 Stap-voor-Stap Uitleg

Stap 1: Het Element Aanmaken

We maken een nieuw div element aan en vullen dit met de gewenste tekst en een sluitknop. 

const toast = document.createElement('div');
toast.classList.add('toast', type);
toast.innerHTML = `<span>${message}</span><button>×</button>`;

Stap 2: Injecteren in de Container

Voeg het nieuwe element toe aan de container die op een vaste plek op het scherm staat.

toastContainer.appendChild(toast);

Stap 3: Automatisch Opruimen

Gebruik een timer om de notificatie na een paar seconden automatisch te laten verdwijnen.

setTimeout(() => {
    toast.remove();
}, 3500);

💻 De Complete Toast Functie

function showToast(message, type = 'info') {
    const toast = document.createElement('div');
    toast.className = `toast ${type}`;
    toast.innerText = message;
    
    container.appendChild(toast);
    
    setTimeout(() => {
        toast.classList.add('hide');
        setTimeout(() => toast.remove(), 300);
    }, 3000);
}

✅ Instructies:

  • Klik op de verschillende knoppen om notificaties van verschillende types te zien verschijnen.
  • Je kunt de notificaties ook handmatig sluiten met het kruisje.

💡 Tips & Tricks

  • Fixed Positioning: Gebruik position: fixed voor de notificatie-container om ervoor te zorgen dat ze altijd zichtbaar blijven, zelfs als de gebruiker scrollt.

⚠️ Veelvoorkomende Fouten

Fout: Geen Animaties

Notificaties die direct in beeld "poppen" voelen onnatuurlijk aan. Gebruik CSS transities of keyframes voor een vloeibaar effect.

/* ✅ GOED: Geanimeerd */
.toast {
    animation: slideIn 0.3s forwards;
}

🚀 Uitbreidingsmogelijkheden

  • Swipe-to-Dismiss: Voeg touch events toe zodat gebruikers notificaties op mobiel kunnen wegswipen.
  • Progress Bar: Voeg een klein balkje onderaan de toast toe dat afneemt naarmate de tijd verstrijkt.

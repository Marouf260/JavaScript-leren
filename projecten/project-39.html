Project 39: Zoek Autocomplete

Advanced

Maak een slimme zoekbalk die suggesties toont terwijl je typt, compleet met tekst-markering.

📚 Wat ga je leren?

  • Het filteren van arrays op basis van gebruikersinvoer.
  • Het dynamisch genereren van een suggestiebox onder een inputveld.
  • Het markeren (highlighten) van overeenkomende tekstfragmenten.

🎯 Belangrijke Concepten

  • Array.filter() – Gebruikt om alleen de elementen uit de dataset te halen die overeenkomen met de zoekopdracht.
  • RegEx (Regular Expressions) – Gebruikt om dynamisch tekst te vervangen door gemarkeerde versies (highlighting).
  • Event Delegation – Luisteren naar kliks op dynamisch gegenereerde suggestie-items.

📝 Stap-voor-Stap Uitleg

Stap 1: Luisteren naar Invoer

Voeg een input event listener toe aan de zoekbalk om elke toetsaanslag te registreren. 

input.addEventListener('input', (e) => {
    const val = e.target.value.toLowerCase();
    filterData(val);
});

Stap 2: De Data Filteren

Filter de lijst met landen en behoud alleen de landen die de ingevoerde tekst bevatten.

const results = countries.filter(item => 
    item.toLowerCase().includes(val)
);

Stap 3: Suggesties Weergeven

Voor elk resultaat wordt een <li> element aangemaakt en toegevoegd aan de suggestielijst.

results.forEach(res => {
    const li = `<li>${res}</li>`;
    suggBox.innerHTML += li;
});

💻 Selectie Afhandelen

Wanneer een gebruiker op een suggestie klikt, wordt de zoekbalk ingevuld en de lijst gesloten.

suggBox.addEventListener('click', (e) => {
    if(e.target.tagName === 'LI') {
        input.value = e.target.innerText;
        suggBox.classList.remove('active');
    }
});

✅ Instructies:

  • Typ een letter (bijv. 'A' of 'P') in de zoekbalk.
  • Bekijk de suggesties die verschijnen en klik op een land om de zoekopdracht te voltooien.

💡 Tips & Tricks

  • Highlighting met RegEx: Gebruik een Regular Expression met de 'gi' vlag (Global & Insensitive) om matches dikgedrukt te maken binnen de suggestietekst.

⚠️ Veelvoorkomende Fouten

Fout: XSS Gevaar bij innerHTML

Het direct injecteren van tekst via innerHTML kan gevaarlijk zijn als de bron onbetrouwbaar is. In dit project gebruiken we een veilige lokale dataset of schonen we de invoer op.

/* VEILIGER: textContent */
const li = document.createElement('li');
li.textContent = match;
suggBox.appendChild(li);

🚀 Uitbreidingsmogelijkheden

  • Fetch API: Haal suggesties op van een echte server (zoals de GitHub API of een weer-service).
  • Toetsenbord Navigatie: Maak het mogelijk om met de pijltjestoetsen door de suggesties te navigeren.

Project 40: Custom Select Dropdown

Advanced

Vervang de standaard browser dropdown door een volledig aanpasbaar en stijlvol select-menu.

📚 Wat ga je leren?

  • Een eigen dropdown‑menu bouwen met gewone HTML‑elementen in plaats van een standaard <select>
  • Met classes en JavaScript de open/dicht‑status van het menu bijhouden
  • Klikken buiten het menu herkennen en het menu dan automatisch sluiten

🎯 Belangrijke Concepten

  • Custom UI boven native elementen – je verbergt het standaard element en bouwt de ervaring zelf op met <div>/<ul>
  • Event bubbling – klik‑events ‘bubbelen’ omhoog naar document, zodat je op één plek een “klik buiten het menu”-controle kunt doen
  • element.contains(e.target) – handig om te checken of een klik binnen of buiten een bepaald element gebeurde

📝 Stap-voor-stap uitleg

Stap 1: Menu open‑ en dichtklappen

Maak de hoofdknop klikbaar en wissel een class om de opties te tonen of te verbergen:

selectBtn.addEventListener('click', () => {
    selectMenu.classList.toggle('active');
});

Stap 2: Een optie kiezen

Lees de tekst van de aangeklikte optie uit en toon die in de knop. Sluit daarna het menu:

options.forEach(option => {
    option.addEventListener('click', () => {
        const selected = option.querySelector('.option-text').innerText;
        sText.innerText = selected;
        options.forEach(opt => opt.classList.remove('selected'));
        option.classList.add('selected');
        selectMenu.classList.remove('active');
    });
});

Stap 3: Buiten het menu klikken

Voeg een click‑listener toe op document en sluit het menu als de klik niet binnen het select‑element was:

document.addEventListener('click', (e) => {
    if (!selectMenu.contains(e.target)) {
        selectMenu.classList.remove('active');
    }
});

💻 Waarde Synchroniseren

Als je een native formulier gebruikt, kun je de geselecteerde waarde synchroniseren met een verborgen input veld.

function updateValue(val) {
    hiddenInput.value = val;
    // Trigger een change event voor frameworks
    hiddenInput.dispatchEvent(new Event('change'));
}

✅ Instructies

  • Klik op de knop “Selecteer je Social Media” om het dropdown‑menu te openen.
  • Klik op één van de opties om die als geselecteerde waarde in de knop te tonen.
  • Klik ergens buiten het menu om het dropdown‑menu weer te sluiten.

💡 Tips & Tricks

  • Toetsenbord‑ondersteuning: wil je dit component echt production‑ready maken, voeg dan ondersteuning toe voor Enter, Escape en pijltjestoetsen.
  • ARIA‑attributen: gebruik role="listbox" en aria-expanded om de toegankelijkheid te verbeteren.

⚠️ Veelvoorkomende fouten

Fout: dropdown blijft open staan

Als je geen listener op document zet, blijft het menu openstaan wanneer de gebruiker ergens anders klikt.

/* Geen click-listener op document */

document.addEventListener('click', () => {
    selectMenu.classList.remove('active');
});

🚀 Uitbreidingsmogelijkheden

  • Zoekveld Toevoegen: Voeg een inputveld toe in de dropdown om grote lijsten met opties te kunnen filteren.
  • Multi-select: Maak het mogelijk om meerdere opties tegelijk te selecteren met checkboxes.

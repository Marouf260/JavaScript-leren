Project 41: Wachtwoord Generator

Data Logic

Bouw een tool die veilige, willekeurige wachtwoorden genereert op basis van jouw voorkeuren.

📚 Wat ga je leren?

  • Het bouwen van een willekeurig algoritme voor het genereren van tekstreeksen.
  • Het toepassen van de Clipboard API om tekst direct naar het klembord van de gebruiker te kopiëren.
  • Het dynamisch filteren van karaktersets op basis van gebruikersvoorkeuren.

🎯 Belangrijke Concepten

  • Willekeurige Selectie – Het kiezen van een willekeurige index uit een string met behulp van Math.random().
  • navigator.clipboard.writeText – De moderne manier om tekst naar het systeemklembord van de gebruiker te kopiëren.

📝 Stap-voor-Stap Uitleg

Stap 1: Karaktersets Definiëren

Maak arrays of strings aan met alle mogelijke karakters die gebruikt mogen worden.

const uppercase = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ';
const lowercase = 'abcdefghijklmnopqrstuvwxyz';
const numbers = '0123456789';
const symbols = '!@#$%^&*()_+~`|}{[]:;?><,./-=';

Stap 2: Gebruikersselectie Verwerken

Controleer welke opties zijn aangevinkt en voeg de bijbehorende karakters toe aan de 'pool'.

let characters = '';
if(upperEl.checked) characters += uppercase;
if(lowerEl.checked) characters += lowercase;
// ...

Stap 3: Het Wachtwoord Genereren

Loop door de gewenste lengte en kies voor elke positie een willekeurig karakter uit de pool.

let password = '';
for(let i=0; i<length; i++){
    let ran = Math.floor(Math.random() * characters.length);
    password += characters[ran];
}
return password;

💻 Kopiëren naar Klembord

Gebruik de moderne Clipboard API voor een soepele gebruikerservaring.

copyBtn.addEventListener('click', () => {
    const password = resultEl.innerText;
    if (!password) return;
    
    navigator.clipboard.writeText(password).then(() => {
        alert('Gekopieerd!');
    });
});

✅ Instructies:

  • Selecteer de gewenste karaktersets met de checkboxes.
  • Klik op 'Genereer Wachtwoord' om een nieuw wachtwoord te maken.

💡 Tips & Tricks

  • Crypto API: Math.random() is niet cryptografisch veilig. Voor echte beveiligingstoepassingen is window.crypto.getRandomValues() een betere keuze.

⚠️ Veelvoorkomende Fouten

Fout: Genereren met 0 pool opties

If the user un-checks ALL checkboxes, your character pool is empty! In a random generator this will cause infinite loops, NaNs or crashes when generating the string.

if(length === 10) generate() // Crashes if pool=''

if(characters.length === 0) return alert('Kies een variabele!');

🚀 Uitbreidingsmogelijkheden

  • Sterktemeter: Voeg een visuele balk toe die aangeeft hoe veilig het gegenereerde wachtwoord is.
  • Wachtwoord Historie: Sla de laatst gegenereerde wachtwoorden lokaal op.

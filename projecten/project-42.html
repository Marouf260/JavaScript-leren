Project 42: RegEx Highlighter

Data Logic

Maak een interactieve tool om Reguliere Expressies (RegEx) live te testen en de resultaten in realtime te markeren.

📚 Wat ga je leren?

  • Werken met Regular Expressions (RegEx) in JavaScript.
  • Het markeren (highlighten) van specifieke tekstdelen in de DOM door strings te vervangen met HTML-tags.

🎯 Belangrijke Concepten

  • String.replace() – Om patronen in tekst te zoeken en deze te vervangen of te beïnvloeden.
  • RegEx Flags – Het gebruik van /g (global) en /i (case-insensitive) om zoekopdrachten te verfijnen.

📝 Stap-voor-Stap Uitleg

Stap 1: Verkrijgen van Invoer

Haal de RegEx-patronen en de testtekst op uit de invoervelden van de UI.

const pattern = document.getElementById('regex').value;
const targetText = document.getElementById('test').value;

Stap 2: RegEx Object Maken

Bouw een nieuw RegExp object dynamisch op basis van de string-invoer van de gebruiker. 

let regex;
try {
    regex = new RegExp(pattern, 'g');
} catch (e) {
    console.log('Fout: ' + e);
}

Stap 3: Highlighter Toepassen

Vervang alle overeenkomende tekstfragmenten door een <mark> element voor visuele feedback.

const html = targetText.replace(regex, match => {
    return `<mark>${match}</mark>`;
});
outputDiv.innerHTML = html;

💻 Foutieve RegEx Veilig Opvangen

function updateHighlights() {
    const pattern = regexInput.value;
    const text = textInput.value;
    
    if (pattern === '') {
        output.innerHTML = text;
        return;
    }

    try {
        const regex = new RegExp(pattern, 'g');
        let highlighted = text.replace(regex, match => `<mark>${match}</mark>`);
        output.innerHTML = highlighted;
        regexInput.classList.remove('error');
    } catch (e) {
        regexInput.classList.add('error');
        output.innerHTML = text;
    }
}

✅ Instructies:

  • Vul een geldig RegEx patroon in (bijv. [0-9]+ voor getallen).
  • Typ of plak tekst in het testgebied om de overeenkomsten direct gemarkeerd te zien.

💡 Tips & Tricks

  • Sanitize: Om XSS te voorkomen, ontdoe gebruikersinput van HTML-tags voordat je deze rendert.

⚠️ Veelvoorkomende Fouten

Fout: Vastlopen door foute syntax

Het direct maken van RegEx zonder try-catch crasht de app bij foutieve syntax.

try { let m = new RegExp(val); } catch(err) { /* handle */ }

🚀 Uitbreidingsmogelijkheden

  • Flags: Voeg checkboxes toe om vlaggen als g, i en m interactief aan te passen.

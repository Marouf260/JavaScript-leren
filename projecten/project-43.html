Project 43: Sorteer Algoritme Visualizer

Data Logic

Visualiseer hoe sorteeralgoritmes werken door willekeurige data live te ordenen met animaties.

📚 Wat ga je leren?

  • Hoe computer algoritmes (zoals Bubble Sort) data in arrays stap voor stap sorteren.
  • Hoe we onzichtbare wiskundige processen visueel kunnen maken in de DOM.

🎯 Belangrijke Concepten

  • Array Swapping – Het omwisselen van twee elementen in een array om de volgorde te corrigeren.
  • Promises & Async – Het vertragen van loops met setTimeout en await om animaties zichtbaar te maken.

📝 Stap-voor-Stap Uitleg

Stap 1: Balkjes Maken

Maak DOM-elementen aan die getallen uit de array representeren via hun CSS-hoogte.

const bar = document.createElement('div');
bar.style.height = `${value * 3}px`;
container.appendChild(bar);

Stap 2: Het Algoritme (Bubble Sort)

Loop door de array en vergelijk aangrenzende elementen. Wissel ze om als de volgorde fout is.

for (let i = 0; i < len; i++) {
    for (let j = 0; j < len - i - 1; j++) {
        if (arr[j] > arr[j + 1]) {
            // Swap logica
        }
    }
}

Stap 3: Visualisatie Vertragen

Pauzeer elke stap in de loop zodat gebruikers de sorteer-animatie live kunnen volgen.

function sleep(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
}

// Binnen de loop:
await sleep(10);

  • Performance: Bij grote datasets is het beter om requestAnimationFrame te gebruiken voor soepelere animaties.

⚠️ Veelvoorkomende Fouten

Fout: De browser bevriest

Zonder `await sleep(ms)` zal de loop zo snel gaan dat de browser 'bevriest' tot de sortering klaar is.

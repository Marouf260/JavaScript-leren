Project 44: Stopwatch & Laps

Data Logic

Maak een nauwkeurige stopwatch met de mogelijkheid om rondetijden vast te leggen en te vergelijken.

📚 Wat ga je leren?

  • Tijd berekenen met JavaScript via de Date API.
  • Het dynamisch bouwen van de DOM om rondetijden live weer te geven.

🎯 Belangrijke Concepten

  • Date.now() – Geeft de huidige tijd in milliseconden sinds 1970. Ideaal als nulpunt voor tijdsmetingen.
  • setInterval – Om de UI elke 10ms te verversen voor een vloeiende weergave.

📝 Stap-voor-Stap Uitleg

Stap 1: De Starttijd Vastleggen

Zodra je op start klikt, leggen we het huidige moment vast als ankerpunt.

startTime = Date.now() - elapsedTime;
timerInterval = setInterval(updateTime, 10);

Stap 2: De Verstreken Tijd Berekenen

Bereken het verschil tussen 'nu' en de opgeslagen starttijd.

function updateTime() {
    elapsedTime = Date.now() - startTime;
    display.innerText = formatTime(elapsedTime);
}

Stap 3: Rondes Registreren

Voeg op aanvraag de huidige tijd toe aan een lijst met laptijden.

const li = document.createElement('div');
li.innerText = formatTime(elapsedTime);
lapList.appendChild(li);

💻 Tijd Formatteren naar MM:SS.ms

function formatTime(time) {
    let date = new Date(time);
    let m = date.getUTCMinutes().toString().padStart(2, '0');
    let s = date.getUTCSeconds().toString().padStart(2, '0');
    let ms = Math.floor(date.getUTCMilliseconds() / 10).toString().padStart(2, '0');
    return `${m}:${s}.${ms}`;
}

✅ Instructies:

  • Klik op de Play-knop om de tijd te starten.
  • Gebruik de Vlag-knop om rondetijden vast te leggen terwijl de klok loopt.
  • Gebruik de Reset-knop om alle tijden te wissen en opnieuw te beginnen.

💡 Tips & Tricks

  • clearInterval: Vergeet niet om het actieve interval te stoppen met clearInterval wanneer je pauzeert of reset.

⚠️ Veelvoorkomende Fouten

Fout: Tellers handmatig ophogen

Als je simpelweg ms++ doet in een interval, loopt de tijd achter bij CPU-belasting. Vertrouw altijd op Date.now().

setInterval(() => ms++, 10); // Loopt onzuiver
elapsedTime = Date.now() - startTime; // Hardware-precies

🚀 Uitbreidingsmogelijkheden

  • Snelste Ronde: Markeer de snelste en langzaamste rondetijden met verschillende kleuren.

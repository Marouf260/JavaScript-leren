Project 45: Tekst Analyse Tool

Data Logic

Word een expert in tekstverwerking door realtime statistieken te berekenen van elke invoer.

📚 Wat ga je leren?

  • Het verwerken van string-data met JavaScript methodes.
  • Het gebruik van Regular Expressions om woorden en zinnen te tellen.

🎯 Belangrijke Concepten

  • String.split() – Tekst opknippen in een array op basis van spaties of leestekens.
  • Array.filter() – Lege resultaten verwijderen voor een nauwkeurige telling.

📝 Stap-voor-Stap Uitleg

Stap 1: Luisteren naar Input

Elke keer als de gebruiker typt, voeren we de analyse opnieuw uit.

textArea.addEventListener('input', () => {
    const text = textArea.value;
    analyzeText(text);
});

Stap 2: Woorden en Karakters Tellen

Verwijder witruimte en gebruik de lengte van de resulterende array/string.

const charCount = text.length;
const words = text.trim().split(/\s+/).filter(w => w.length > 0);
const wordCount = words.length;

Stap 3: Zinnen Detecteren

Split de tekst op leestekens zoals punten, vraagtekens en uitroeptekens.

const sentences = text.split(/[.!?]+/).filter(s => s.trim().length > 0);

✅ Instructies:

  • Typ of plak een tekst in het grote tekstvak.
  • Bekijk de realtime updates van de statistieken onderaan.

💡 Tips & Tricks

  • Leestijd: Ga uit van een gemiddelde snelheid van 200 woorden per minuut voor de berekening.

⚠️ Veelvoorkomende Fouten

Fout: Verkeerd tellen van woorden door spaties

Simpelweg splitten op een spatie ' ' resulteert in extra 'woorden' bij dubbele spaties of nieuwe regels.

// FOUT
text.split(' ').length;

// GOED
text.trim().split(/\s+/).filter(w => w !== '').length;

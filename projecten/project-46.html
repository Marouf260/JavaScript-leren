Project 46: Quote & Color Generator

Data Logic

Genereer willekeurige quotes en verander de achtergrondkleur van de pagina voor een dynamische ervaring.

📚 Wat ga je leren?

  • Het willekeurig selecteren van data uit arrays.
  • Het manipuleren van CSS styles (zoals backgroundColor) via JavaScript.

🎯 Belangrijke Concepten

  • Math.random() – Gebruikt om een willekeurig getal tussen 0 en 1 te genereren.
  • Math.floor() – Om getallen af te ronden naar het dichtstbijzijnde gehele getal (indexen).

📝 Stap-voor-Stap Uitleg

Stap 1: Data Voorbereiden

Maak arrays met diverse quotes en bijbehorende hex-kleurcodes.

const quotes = [{ text: "...", author: "..." }, ...];
const colors = ["#0f172a", "#3b82f6", ...];

Stap 2: Willekeurige Index Kiezen

Bereken een index binnen de grenzen van de array-lengte.

const index = Math.floor(Math.random() * quotes.length);

Stap 3: UI Updaten

Pas de tekst en de achtergrondkleur van de body aan.

document.body.style.backgroundColor = colors[index];
quoteElement.innerText = quotes[index].text;

💻 De Generator Functie

function generate() {
    const randomIdx = Math.floor(Math.random() * quotes.length);
    const selected = quotes[randomIdx];
    
    // Smooth transition
    quoteBox.style.opacity = 0;
    
    setTimeout(() => {
        document.body.style.backgroundColor = colors[randomIdx];
        textEl.innerText = selected.text;
        authorEl.innerText = "- " + selected.author;
        quoteBox.style.opacity = 1;
    }, 300);
}

✅ Instructies:

  • Klik op de knop 'Nieuwe Quote' om een nieuwe combinatie te genereren.
  • De achtergrondkleur verandert mee met de sfeer van de quote.

💡 Tips & Tricks

  • Contrast: Let op dat de tekstkleur leesbaar blijft bij donkere of lichte achtergronden.

⚠️ Veelvoorkomende Fouten

Fout: Index buiten bereik

Zonder Math.floor krijg je decimalen, wat geen geldige array-index is.

let idx = Math.random() * arr.length; // Fout: bijv. 2.45
let idx = Math.floor(Math.random() * arr.length); // Goed: 2

Project 47: Valuta Omrekenaar (Mock API)

Data Logic

Leer hoe je wisselkoersen berekent en verwerkt met een gesimuleerde API-omgeving.

📚 Wat ga je leren?

  • Het afhandelen van 'change' en 'input' events in formulieren.
  • Het werken met wisselkoersen in een JSON-formaat.

🎯 Belangrijke Concepten

  • Event Listeners – Luisteren naar veranderingen in select-velden en inputveld-waardes.
  • Wiskundige Validatie – Zorgen dat berekeningen nauwkeurig blijven tot 2 decimalen met toFixed(2).

📝 Stap-voor-Stap Uitleg

Stap 1: Wijzigingen Detecteren

Luister naar veranderingen in de gekozen valuta's of de ingevoerde bedragen.

currencyEl_one.addEventListener('change', calculate);
amountEl_one.addEventListener('input', calculate);

Stap 2: Koers Opzoeken

Haal de actuele koers op uit een object (of externe API) op basis van de gekozen valuta's.

const rate = exchangeRates[currencyOne][currencyTwo];

Stap 3: Resultaat Berekenen

Vermenigvuldig het bedrag met de koers en update het doelveld.

amountEl_two.value = (amountEl_one.value * rate).toFixed(2);

💻 De Berekening Functie

function calculate() {
    const currencyOne = currencyEl1.value;
    const currencyTwo = currencyEl2.value;
    const amount1 = amountEl1.value;
    
    // In een echte app zou je hier een fetch() doen
    const rate = mockRates[currencyOne][currencyTwo];
    
    rateDisplay.innerText = `1 ${currencyOne} = ${rate} ${currencyTwo}`;
    amountEl2.value = (amount1 * rate).toFixed(2);
}

✅ Instructies:

  • Kies een basis-valuta en vul een bedrag in.
  • Kies de doel-valuta om direct het omgerekende bedrag te zien.
  • Gebruik de 'Swap' knop om de twee valuta's om te draaien.

💡 Tips & Tricks

  • Rate Limiting: Bij echte API's is het verstandig om resultaten te cachen (bewaren) om onnodige server-verzoeken te voorkomen.

⚠️ Veelvoorkomende Fouten

Fout: Verkeerde types vermenigvuldigen

Input-waardes zijn altijd strings. JavaScript rekent vaak automatisch om, maar het is veiliger om parseFloat() te gebruiken.

let total = parseFloat(input.value) * rate;

🚀 Uitbreidingsmogelijkheden

  • Echte API: Vervang de mock-data door een fetch-aanroep naar bijv. exchangerate-api.com.

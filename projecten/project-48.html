Project 48: Simpele Markdown Previewer

Data Logic

Bouw een parser die Markdown-tekst zoals headers en dikgedrukte woorden realtime omzet naar HTML.

📚 Wat ga je leren?

  • Het gebruik van Regular Expressions (RegEx) om specifieke tekstpatronen te vinden.
  • Het realtime updaten van de DOM op basis van textarea-invoer.

🎯 Belangrijke Concepten

  • String.replace() – Het hart van onze parser, die patterns vervangt door HTML tags.
  • Global (g) & Multiline (m) Flags – Om patronen over de gehele tekst en op nieuwe regels te vinden.

📝 Stap-voor-Stap Uitleg

Stap 1: Veranderingen Onderscheppen

Luister naar de input event op de editor om direct te reageren op elke toetsaanslag.

editor.addEventListener('input', () => {
    preview.innerHTML = parseMarkdown(editor.value);
});

Stap 2: RegEx Patronen Toepassen

Gebruik vervangingsregels voor headers, dikgedrukte en schuingedrukte tekst.

text = text.replace(/^# (.*)$/gm, '<h1>$1</h1>');
text = text.replace(/\*\*(.*)\*\*/g, '<strong>$1</strong>');

Stap 3: Nieuwe Regels Behandelen

Markdown gebruikt vaak gewone enters voor witruimte. Zet deze om naar <br> tags. 

text = text.replace(/\n/g, '<br>');

💻 De Parser Functie

function parseMarkdown(text) {
    let html = text;
    // Headers
    html = html.replace(/^#\s(.*)$/gm, '<h1>$1</h1>');
    html = html.replace(/^##\s(.*)$/gm, '<h2>$1</h2>');
    // Bold/Italic
    html = html.replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>');
    html = html.replace(/\*(.*?)\*/g, '<em>$1</em>');
    return html;
}

✅ Instructies:

  • Typ Markdown in het linkervak (bijv. # Titel).
  • Gebruik **tekst** voor dikgedrukt en *tekst* voor schuin.
  • Bekijk het direct gerenderde resultaat in het rechtervak.

💡 Tips & Tricks

  • Order matters: Pas complexere RegEx regels eerst toe voordat je eenvoudige tekens (zoals witruimte) vervangt.

⚠️ Veelvoorkomende Fouten

Fout: Te gulzige (greedy) matching

RegEx probeert standaard zoveel mogelijk tekst te pakken. Gebruik .*? in plaats van .* om te stoppen bij de eerste match.

// FOUT: pakt alles tussen eerste en LAATSTE ster
text.replace(/\*(.*)\*/g, '...');

// GOED: pakt alles tussen eerste en VOLGENDE ster
text.replace(/\*(.*?)\*/g, '...');

Project 49: Notitie App (Local Storage)

Data Logic

Bouw een handige notitie-app die je gegevens veilig in de browser bewaart met LocalStorage.

📚 Wat ga je leren?

  • Het persistent opslaan van data met de localStorage API.
  • Het dynamisch creëren en verwijderen van complexe DOM-elementen.

🎯 Belangrijke Concepten

  • JSON.stringify() – Zet arrays of objecten om naar een string voor opslag.
  • JSON.parse() – Zet opgeslagen tekst weer terug naar bruikbare JavaScript data.

📝 Stap-voor-Stap Uitleg

Stap 1: Data Laden bij Opstarten

Haal bestaande notities op en zet ze om naar een array.

const notes = JSON.parse(localStorage.getItem('notes')) || [];

Stap 2: Notitie Elementen Bouwen

Maak een functie die de HTML-structuur voor een notitie genereert en toevoegt aan de grid.

const note = document.createElement('div');
note.classList.add('note');
note.innerHTML = `<textarea>...</textarea>`;

Stap 3: Automatisch Opslaan

Update de opslag elke keer als er tekst wordt aangepast of een notitie wordt verwijderd.

localStorage.setItem('notes', JSON.stringify(data));

💻 Opslag Updaten

function updateLS() {
    const notesText = document.querySelectorAll('textarea');
    const notes = [];
    notesText.forEach(note => notes.push(note.value));
    localStorage.setItem('notes', JSON.stringify(notes));
}

✅ Instructies:

  • Klik op '+ Nieuwe Notitie' om een extra vlak toe te voegen.
  • Typ je tekst; deze wordt direct en automatisch bewaard.
  • Verwijder een notitie door op de prullenbak te klikken.

💡 Tips & Tricks

  • Quotas: LocalStorage heeft een limiet (vaak 5MB). Voor enorme hoeveelheden data zijn IndexedDB of een database-server beter geschikt.

⚠️ Veelvoorkomende Fouten

Fout: Objecten direct opslaan

LocalStorage accepteert alleen strings. Als je een object opslaat zonder stringify, krijg je de tekst "[object Object]" terug.

// FOUT
localStorage.setItem('user', {name: 'Dez'});

// GOED
localStorage.setItem('user', JSON.stringify({name: 'Dez'}));

Project 50: Interactieve Paginering

Data Logic

Verdeel grote hoeveelheden data over meerdere pagina's met een overzichtelijk navigatiesysteem.

📚 Wat ga je leren?

  • Het berekenen van start- en eindposities binnen een array (slice logica).
  • Het dynamisch genereren van navigatieknoppen op basis van data-lengte.

🎯 Belangrijke Concepten

  • Math.ceil() – Afronden naar boven om het totaal aantal pagina's te bepalen.
  • Array.slice(start, end) – Een kopie maken van een specifiek deel van de data.

📝 Stap-voor-Stap Uitleg

Stap 1: Variabelen Instellen

Houd bij op welke pagina de gebruiker zit en hoeveel rijen er per pagina getoond moeten worden.

let currentPage = 1;
const rowsPerPage = 5;

Stap 2: Data Segmenteren

Selecteer alleen de items die bij de huidige pagina horen.

const start = (currentPage - 1) * rowsPerPage;
const end = start + rowsPerPage;
const pageItems = items.slice(start, end);

Stap 3: Knoppen Genereren

Bereken hoeveel knoppen er nodig zijn en voeg click events toe om de pagina te wisselen.

const pageCount = Math.ceil(items.length / rowsPerPage);

💻 De Render Logica

function displayList(items, wrapper, rows, page) {
    wrapper.innerHTML = "";
    page--;
    
    const start = rows * page;
    const end = start + rows;
    const paginatedItems = items.slice(start, end);

    paginatedItems.forEach(item => {
        const li = document.createElement('li');
        li.innerText = item;
        wrapper.appendChild(li);
    });
}

✅ Instructies:

  • Klik op de paginanummers onderaan om door de lijst te navigeren.
  • Merk op hoe de lijst direct verspringt zonder de hele browser te herladen.

💡 Tips & Tricks

  • Dynamic UI: Voeg 'Vorige' en 'Volgende' knoppen toe voor een nog betere gebruikerservaring bij lange lijsten.

⚠️ Veelvoorkomende Fouten

Fout: Index verwarring

Omdat arrays bij 0 beginnen, moet je altijd 1 van het paginanummer aftrekken bij de berekening.

let start = page * rows; // FOUT
let start = (page - 1) * rows; // GOED

🚀 Uitbreidingsmogelijkheden

  • Search integration: Zorg dat de paginering meebeweegt als de gebruiker de lijst filtert via een zoekveld.

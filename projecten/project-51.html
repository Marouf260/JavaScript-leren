Project 51: Boter, Kaas en Eieren

Intermediate

Bouw een klassiek Boter, Kaas en Eieren spel en leer hoe je complexe spellogica beheert met JavaScript arrays en conditionele checks.

📚 Wat ga je leren?

In dit project verdiep je jouw kennis van JavaScript logica door een systeem te bouwen dat beslissingen neemt op basis van gebruikersinvoer:

  • Grid Management: Hoe je een visueel raster koppelt aan een data-structuur (array).
  • Win-Algoritme: Het controleren van meerdere mogelijke uitkomsten in een dataset.
  • Spel-State: Het bijhouden van beurten, winstcondities en actieve statussen.
  • Visuele Interactie: Dynamische feedback geven aan de gebruiker bij elke zet.

🎯 Kernconcepten

  • Stateful Arrays: Gebruik van een array om de 'status' van elk vakje (X, O of leeg) vast te leggen.
  • Multidimensionale Arrays (Logisch): Hoewel we een 1D array gebruiken, denken we in coördinaten (0-8) om rijen en kolommen te representeren.
  • De Ternary Operator: Een compacte manier om tussen 'X' en 'O' te wisselen: currentPlayer === 'X' ? 'O' : 'X'.
  • Array Prototypes: Gebruik van .includes() om te checken op een gelijkspel.

📝 Stap-voor-Stap Uitleg

Stap 1: De Data-structuur

We hebben een 'board' nodig dat fungeert als de bron van waarheid voor de game.

let board = ["", "", "", "", "", "", "", "", ""];

Uitleg: Elk element in de array komt overeen met een data-index in onze HTML. Dit maakt de koppeling tussen code en scherm heel direct.

Stap 2: Klik-logica Implementeren

Wat gebeurt er als een student op een vakje klikt?

function handleCellClick(e) {
    const index = e.target.dataset.index;
    if (board[index] !== "" || !gameActive) return;
    
    board[index] = currentPlayer;
    e.target.innerText = currentPlayer;
    checkResult();
}

Uitleg: De if-check is cruciaal. Deze voorkomt dat een speler een bezet vakje overschrijft of doorspeelt nadat er al iemand gewonnen heeft.

Stap 3: Het Win-Algoritme

We vergelijken ons huidige bord met een lijst van 8 mogelijke winnende lijnen.

const winLines = [[0,1,2], [3,4,5], ...];
for (let line of winLines) {
    const [a, b, c] = line;
    if (board[a] && board[a] === board[b] && board[a] === board[c]) {
        // We hebben een winnaar!
    }
}

Uitleg: We pakken drie indexen (a, b, c) en kijken of de inhoud van die posities in onze board array identiek is én niet leeg is.

⚠️ Veelvoorkomende Fouten

Fout: Global scope vervuiling

Het vergeten te resetten van de board array bij een herstart. De visuele cellen worden vaak wel leeggemaakt, maar de JavaScript data blijft dan 'denken' dat het bord nog vol is.

Fout: Race conditions

Het wisselen van de speler (X naar O) voordat de win-check is gedaan. Hierdoor kan de verkeerde speler als winnaar worden uitgeroepen in de interface.

💡 Tips voor Studenten

  • Console Log is je vriend: Gebruik console.table(board) om je 1D array in te zien bij elke zet.
  • DRY (Don't Repeat Yourself): Gebruik een loop voor je win-checks in plaats van 8 keer een handmatige if statement te schrijven.
  • Styling: Gebruik CSS-klassen zoals .win-highlight om de winnaar echt te laten opvallen in de UI.

🚀 Uitbreidingsmogelijkheden

Klaar voor de volgende stap? Probeer deze uitdagingen:

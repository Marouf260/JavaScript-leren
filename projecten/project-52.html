Project 52: Memory Card Game

Intermediate

Bouw een interactief geheugenspel en leer hoe je complexe toestanden beheert, 3D CSS animaties gebruikt en data-attributen inzet.

📚 Wat ga je leren?

In dit project leer je hoe je een interactieve spelervaring creëert door visuele effecten te combineren met logica:

  • Shuffle Logica: Hoe je een dataset op een eerlijke manier willekeurig door elkaar husselt.
  • Timing & Sequentie: Het gebruik van setTimeout om acties te pauzeren zodat de speler de tijd heeft om te kijken.
  • Complex Statusbeheer: Het voorkomen van ongewenste acties (zoals te veel kaarten omdraaien) tijdens een animatie.
  • 3D CSS: Het bouwen van een kaart die écht lijkt om te draaien in een driedimensionale ruimte.

🎯 Kernconcepten

  • Fisher-Yates Shuffle: Het standaard algoritme voor het willekeurig ordenen van arrays.
  • Data Attributes: De dataset property in JS gebruiken om metadata (zoals de emoji waarde) aan een element te koppelen.
  • CSS Perspective: Hoe je diepte creëert in een 2D vlak zodat 3D rotaties er goed uitzien.
  • State Guards: Het gebruik van lockBoard variabelen om 'gekke' gebruikersinteracties te blokkeren.

📝 Stap-voor-Stap Uitleg

Stap 1: De Kaarten Schudden

Voordat we de kaarten tekenen, moeten we ze door elkaar husselen zodat elk spel anders is.

function shuffle(array) {
    for (let i = array.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [array[i], array[j]] = [array[j], array[i]];
    }
}

Uitleg: We loopen van achter naar voren door de array en wisselen elk item om met een willekeurig ander item in de lijst. Dit is veel betrouwbaarder dan Math.random() - 0.5.

Stap 2: De Kaart-Flip en Guards

We moeten heel voorzichtig zijn met wanneer een student mag klikken.

function flipCard() {
    if (lockBoard) return;
    if (this === firstCard) return;
    this.classList.add('flipped');
    // Verwerk eerste of tweede kaart...
}

Uitleg: lockBoard zorgt ervoor dat je niet op een derde kaart kunt klikken terwijl de eerste twee nog aan het terugdraaien zijn. De tweede check voorkomt dat je twee keer op dezelfde kaart klikt.

Stap 3: Vergelijken en Timer

Als er twee kaarten open liggen, vergelijken we ze via hun data-attribuut.

if (firstCard.dataset.waarde === secondCard.dataset.waarde) {
    disableCards(); // Match!
} else {
    unflipCards(); // Geen match, draai terug met vertraging
}

Uitleg: Als er geen match is, gebruiken we setTimeout voor 1000ms. Dit geeft de student 1 seconde de tijd om de emoji's te onthouden voordat ze weer verdwijnen.

⚠️ Veelvoorkomende Fouten

Fout: Geen matching data

Vaak vergeten studenten de emoji of ID op de .card container te zetten via dataset, waardoor JS nooit weet welke kaarten bij elkaar horen.

Fout: Z-index issues

Zonder preserve-3d en backface-visibility flikkert de kaart onnatuurlijk of zie je de 'voorkant' al voordat de kaart helemaal gedraaid is.

💡 Tips voor Studenten

  • CSS Transitions: Experimenteer met de cubic-bezier timing functie om de kaart-flip een 'bounce' effect te geven.
  • Modulariteit: Splits je code op in functies zoals createBoard, checkForMatch en resetBoard om het overzichtelijk te houden.
  • Array Spread: Gebruik [...array, ...array] om heel snel je set kaarten te verdubbelen voor paren.

🚀 Uitbreidingsmogelijkheden

  • Tijdsdruk: Voeg een countdown timer toe. Kun je alle matches vinden binnen 60 seconden?
  • Dynamic Grid: Laat de gebruiker de grootte van het veld kiezen (bijv. 2x2, 4x4, 6x6).
  • Persistente High-score: Sla het laagste aantal pogingen op in localStorage zodat studenten zichzelf kunnen uitdagen.

Project 53: Reactie Timer

Intermediate

Test je reflexen tot op de milliseconde en leer hoe je een robuuste 'state-machine' bouwt waarbij acties afhankelijk zijn van de huidige status van het spel.

📚 Wat ga je leren?

In dit project leer je hoe je nauwkeurige tijdmetingen uitvoert en hoe je gebruikersinteractie beheert in een tijdgevoelige applicatie:

  • Milliseconde Precisie: Berekeningen maken met de Date.now() timestamp.
  • State Machines: Logica bouwen die reageert op basis van de huidige modus (Klaar, Wachten, Klik Nu).
  • Async Control: Het gebruik van setTimeout voor willekeurige intervals en clearTimeout voor annuleringen.
  • Visuele States: Hoe je kleuren en iconen inzet om de status van een systeem direct te communiceren.

🎯 Kernconcepten

  • Date.now(): Geeft het aantal milliseconden weer sinds 1 januari 1970. Door twee van deze waarden van elkaar af te trekken, krijg je de verstreken tijd.
  • State-based Logic: Het spel heeft 5 fasen: start, waiting, go, result, en early. Elke fase heeft zijn eigen regels.
  • Willekeurige Intervals: Math.random() gebruiken om te voorkomen dat de gebruiker de timer kan voorspellen.
  • UI Synchronization: Het synchroon houden van de interne JavaScript status en de visuele CSS-klassen.

📝 Stap-voor-Stap Uitleg

Stap 1: De Start en de Timer

Zodra de student klikt om te beginnen, starten we een onzichtbare timer.

const delay = Math.floor(Math.random() * 3500) + 1500;
timerId = setTimeout(() => {
    state = 'go';
    startTime = Date.now();
    // Kleur naar groen...
}, delay);

Uitleg: We kiezen een willekeurige tijd tussen 1.5 en 5 seconden. Pas als die tijd om is, leggen we de startTime vast.

Stap 2: De "Te Vroeg" Check

Wat gebeurt er als een student te ongeduldig is?

if (state === 'waiting') {
    clearTimeout(timerId);
    state = 'early';
    // Toon waarschuwing...
}

Uitleg: Als de status nog waiting is, betekent dit dat de timer nog loopt. We moeten deze direct stoppen met clearTimeout, anders springt het scherm alsnog op groen terwijl de student al af is.

Stap 3: Reactietijd Berekenen

Als het scherm groen is, meten we het verschil.

const reactionTime = Date.now() - startTime;

Uitleg: Date.now() op het moment van de klik minus de startTime (het moment waarop het groen werd) geeft het exacte aantal milliseconden dat de student erover deed.

⚠️ Veelvoorkomende Fouten

Fout: Zombie Timers

Het niet aanroepen van clearTimeout. Hierdoor kan er een nieuwe timer starten terwijl de oude nog loopt, wat leidt tot schermen die willekeurig van kleur flitsen.

Fout: Floating point precision

Het proberen te gebruiken van setInterval om de tijd op te tellen (bijv. elke 10ms). Dit is onnauwkeurig door browser-vertraging. Gebruik altijd het verschil tussen twee timestamps.

💡 Tips voor Studenten

  • UX Feedback: Gebruik geluidseffecten (zoals een korte 'ping') om de reactietijd-ervaring nog intenser te maken.
  • State Helpers: Maak een functie updateUI() die alle visuele elementen in één keer bijwerkt op basis van de huidige status om fouten te voorkomen.
  • Performance: Voorkom zware berekeningen in de periode dat het scherm groen is; elke milliseconde telt voor de student!

🚀 Uitbreidingsmogelijkheden

  • Gemiddelde Calculator: Laat de student 5 keer achter elkaar proberen en bereken het gemiddelde resultaat.
  • Leaderboard: Sla de snelste 3 tijden op in localStorage en toon deze als een lijstje.
  • Moeilijkheidsgraad: Maak het 'klik vlak' kleiner of laat het bewegen over het scherm om de uitdaging te vergroten.

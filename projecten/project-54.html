Project 54: Typing Speed Test

Intermediate

Test je typesnelheid en nauwkeurigheid in real-time. Leer hoe je tekst verwerkt op karakter-niveau en complexe statistieken zoals WPM berekent.

📚 Wat ga je leren?

In dit project duik je diep in tekstverwerking en real-time data visualisatie:

  • Dynamic Span Injection: Hoe je een string omzet in individuele DOM-elementen voor per-karakter styling.
  • Input Monitoring: Het reageren op gebruikersinvoer en deze direct vergelijken met een 'bron van waarheid'.
  • WPM Algoritme: Het berekenen van de 'Words Per Minute' standaard (5 karakters = 1 woord).
  • State Awareness: De applicatie laten weten wanneer de test gestart, bezig of voltooid is.

🎯 Kernconcepten

  • String Splitting: Gebruik van .split('') om een zin te transformeren naar een array van karakters.
  • DOM Comparison: Het loopen door een lijst van <span> elementen om hun inhoud te matchen met de value van een input-veld.
  • Real-time Math: Tijdmetingen combineren met het aantal goed getypte karakters om een dynamische score te tonen.
  • Event Filtering: Het negeren van input als de test al klaar is of nog niet gestart.

📝 Stap-voor-Stap Uitleg

Stap 1: Tekst Omzetten naar UI

We kunnen niet zomaar een blok tekst tonen als we individuele letters willen inkleuren.

const charNodes = quote.split('').map(char => {
    const span = document.createElement('span');
    span.innerText = char;
    return span;
});

Uitleg: Door elk karakter in een eigen span te zetten, kunnen we later via JS heel makkelijk .classList.add('correct') aanroepen op één specifieke letter.

Stap 2: Input Vergelijken

Bij elke input event loopen we door de spans en vergelijken we de indexen.

const inputArr = input.value.split('');
spans.forEach((span, i) => {
    const typed = inputArr[i];
    if (typed == null) span.className = 'char';
    else if (typed === span.innerText) span.classList.add('correct');
    else span.classList.add('error');
});

Uitleg: We vergelijken de letter op positie i van de gebruiker met de letter op positie i in de brontekst. Als de gebruiker nog niet bij die letter is (typed is null), halen we de kleurtjes weg.

Stap 3: WPM Berekenen

De officiële WPM berekening gebruikt 5 karakters als één gemiddeld woord.

const minutes = (Date.now() - startTime) / 60000;
const wpm = Math.round((correctChars / 5) / minutes);

Uitleg: We meten het aantal minuten (milliseconden / 60.000) en delen het aantal woorden door die tijd. Dit geeft een eerlijke score, ongeacht de lengte van de woorden.

⚠️ Veelvoorkomende Fouten

Fout: Foutieve WPM bij start

Het proberen te berekenen van de WPM in de eerste milliseconde. Dit leidt tot een Infinity of NaN foutmelding. Voer de berekening pas uit na 1 seconde of voeg een check toe.

Fout: Backspace beheer

Het vergeten de error klasse te verwijderen als een gebruiker een fout herstelt met backspace. Zorg dat je de status van élke span opnieuw evalueert bij elke wijziging.

💡 Tips voor Studenten

  • Focus Management: Gebruik input.focus() automatisch bij het laden van de pagina en na een herstart voor een snellere workflow.
  • Cursor Visueel: Voeg een active-cursor klasse toe aan het karakter waar de gebruiker nu is, om de focus te verbeteren.
  • Responsive: Zorg dat de tekst netjes 'wrapt' in de container, anders wordt je test onbruikbaar op kleinere schermen.

🚀 Uitbreidingsmogelijkheden

  • Quote API: Gebruik fetch() om elke ronde een nieuwe, willekeurige quote op te halen van een externe server.
  • Nauwkeurigheid: Toon een 'Accuracy' percentage. (Goede karakters / Totaal getypte karakters * 100).
  • Moeilijkheidsgraad: Voeg een timer toe; hoeveel woorden kun je typen in exact 60 seconden?

Project 55: Snake (DOM Grid)

Advanced

Bouw de klassieke Snake game en leer hoe je een complex coördinatensysteem en game-loop beheert met JavaScript arrays en CSS Grid.

📚 Wat ga je leren?

In dit project bouw je een volledige 2D-game logica op gebaseerd op een raster (grid). Je gaat leren:

  • State Representation: Een fysieke slang vertalen naar een array van {x, y} coördinaten.
  • Game Loop: Het creëren van de hartslag van een spel met setInterval om berekeningen periodiek uit te voeren.
  • Grid Mapping: Het berekenen van een 1D index (in HTML) vanuit 2D coördinaten (in JavaScript).
  • Array Manipulatie (unshift/pop): In plaats van de gehele slang te bewegen, voegen we enkel een nieuw "hoofd" toe vooraan de array en verwijderen we de "staart" aan het einde.

🎯 Kernconcepten

  • 1D naar 2D Mapping: Onze HTML heeft 400 losse "cell"-divs zonder structuur. Door de wiskundige formule index = y * breedte + x te gebruiken, kunnen we exact de juiste div selecteren via JavaScript.
  • Reference Types vs Values: Het kopiëren van het hoofd van de slang met de spread operator ({...snake[0]}) zodat het origineel niet wordt overschreven voordat we berekeningen uitvoeren.
  • Direction Vectors: De richting wordt opgeslagen als een "vector", bijvoorbeeld {x: 0, y: -1} betekent omhoog (0 op de x-as, -1 op de y-as).

📝 Stap-voor-Stap Uitleg

Stap 1: De Slang Laten Bewegen

De logica van bewegen is een slimme truc van array-manipulatie.

const head = { x: snake[0].x + dir.x, y: snake[0].y + dir.y };
snake.unshift(head); // Nieuw hoofd vooraan
if (!heeftAppelGegeten) {
    snake.pop(); // Verwijder oude staart
}

Uitleg: We verplaatsen de slang niet echt div voor div. We voegen gewoon een nieuw hoofdje toe in de looprichting en hakken het laatste stukje staart eraf. Als er een appel is gegeten, hakken we de staart *niet* af, waardoor de slang automatisch langer wordt!

Stap 2: Input Handling en Beperkingen

We luisteren naar het toetsenbord, maar voorkomen dat de slang "keert" op zichzelf.

window.addEventListener('keydown', e => {
    if (e.key === 'ArrowUp' && dir.y === 0) nextDir = { x: 0, y: -1 };
});

Uitleg: De check dir.y === 0 is cruciaal. Deze zegt: "We mogen alleen omlaag of omhoog draaien, als we op dit moment puur verticaal (links of rechts) aan het bewegen zijn." Dit voorkomt instante gameovers door achteruit te lopen.

Stap 3: Het Speelveld Updaten (Renderen)

Aan het einde van elke interval (tick) tekenen we de nieuwe wereld.

function render() {
    // Wis alles eerst
    [...grid.children].forEach(c => c.className = 'cell');
    // Teken appel
    getCell(apple.x, apple.y).classList.add('apple');
    // Teken hele slang opnieuw
    snake.forEach(segment => {
        getCell(segment.x, segment.y).classList.add('snake-body');
    });
}

⚠️ Veelvoorkomende Fouten

Fout: Dubbele inputs in één Tick

Als je toetsenbord direct dir (richting) wijzigt, kun je héél snel "Links" en dan "Omlaag" typen in de tijd van 1 game-tick. Hierdoor draai je de slang 180 graden de dood in. Oplossing: gebruik een nextDir buffer variabele die pas door het game mechanisme wordt toegepast op het moment van de game-tick.

Fout: Appels spawnen OP de slang

Vaak worden nieuwe coördinaten voor het voedsel via een simpele Math.random() bepaald. Dit kan echter ín het lichaam van de slang vallen. Zorg altijd voor een while-loop met validation check (snake.some(...)) tijdens het spawnen.

💡 Tips voor Studenten

  • Prestaties (Performance): Deze manier van renderen (alle 400 div classes wissen en overschrijven) heet DOM re-painting. Voor deze game grootte okee, maar voor geavanceerde complexe berekeningen zoals bij project "Particles", kun je beter gebruikmaken van de Canvas Web API.
  • Styling: Speel met border-radius (bijvoorbeeld ronde hoeken geven afhankelijk van de vector) op de specifieke cellen om de slang echt als slang te tonen!

🚀 Uitbreidingsmogelijkheden

  • Acceleratie: Probeer de snelheid via setInterval stapsgewijs 10ms sneller te zetten na elke gegeten appel. Tip: dit vereist het wissen via clearInterval() en opnieuw starten.
  • Muren doorbreken (Pacman stijl): Pas de collision-logica zo aan dat als speler de muur links passeert, de speler aan de rechterzijde verschijnt in plaats van the sterven (Wrapping around the grid).

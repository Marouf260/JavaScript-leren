Project 57: Steen, Papier, Schaar

Beginner / Intermediate

Test je geluk tegen de computer in de ultieme Steen-Papier-Schaar arena. Leer hoe je datastructuren gebruikt om winstcondities te optimaliseren.

📚 Wat ga je leren?

Dit spel lijkt simpel, maar dwingt je na te denken over het gestructureerd opslaan van spelregels:

  • Data Dictionaries (Maps): Gebruikmaken van objecten om krachtige en makkelijk leesbare regels te definiëren, in plaats van tientallen if...else statements.
  • Pseudo-Randomness: De computer een eerlijke keuze laten maken door een array-index te selecteren via Math.random().
  • State Guards: Een isPlaying boolean gebruiken om te voorkomen dat knoppen gespammed worden tijdens een actieve ronde.

🎯 Kernconcepten

  • Object Lookups: Met rules['steen'] vraag je direct aan een object wat de zwakte van 'steen' is ('schaar'). Dit voorkomt spaghetti-code.
  • Delay UI (Tijdelijke status): Door de definitieve uitslag te vertragen met setTimeout ontstaat er anticipatie. De computer lijkt "na te denken" (rollen animatie).
  • Data Attributen: Het opslaan van de waarde per knop direct in de HTML met data-choice="steen" en dit uitlezen via dataset.choice in JavaScript.

📝 Stap-voor-Stap Uitleg

Stap 1: Spelregels Object Georiënteerd Maken

We maken een "Map" van wat wint waarvan. De sleutel is de keuze, de waarde is datgene wat deze keuze verslaat.

const rules = {
    'steen': 'schaar',  // Steen verslaat schaar
    'papier': 'steen',  // Papier verslaat steen
    'schaar': 'papier'  // Schaar verslaat papier
};

Uitleg: Nu kunnen we met 1 regel code checken of we gewonnen hebben: if (rules[player] === computer) { win() }. Extreem efficiënt!

Stap 2: De Computer's Beurt

De computer moet eerlijk rollen, 33.3% kans op elke optie.

const choices = Object.keys(rules); // ['steen', 'papier', 'schaar']
const randIndex = Math.floor(Math.random() * choices.length);
const computer = choices[randIndex];

Uitleg: Math.random() geeft een getal tussen 0 (inclusief) en 1 (exclusief). Vermenigvuldigd met lengte 3 geeft het een getal van 0 tot 2.999. Math.floor rondt dit af naar index 0, 1 of 2.

Stap 3: CSS Toggles voor Feedback

Kleur is zeer cruciaal in games.

// Eerst vorige resutlaat-kleuren wissen
resultMsg.className = "result-message";

if (win) resultMsg.classList.add('win');   // Groen
if (lose) resultMsg.classList.add('lose'); // Rood

⚠️ Veelvoorkomende Fouten

Fout: If-else Oerwoud

Het uitschrijven van alle negen combinaties met if (p === 'steen' && c === 'papier') ... is vreselijk om te onderhouden. Gebruik altijd een datastructuur zoals het rules object om de complexiteit te versimpelen.

Fout: Button Spam

Omdat de computer 800ms nodig heeft om na te denken in onze animatie, kan een speler ondertussen nog 5 keer klikken, waardoor de timeout 5 keer achter elkaar wordt afgeschoten. Voeg een isPlaying = true lock toe om spam te blokkeren.

💡 Tips voor Studenten

  • Opschalen (Lizard Spock): Het voordeel van de rules map aanpak is dat als je de game uitbreidt (bijv. Big Bang Theory's Steen-Papier-Schaar-Hagedis-Spock), je alleen het rules object hoeft te updaten in plaats van honderden if-statements. (Een keuze krijgt dan een array van vijanden om te verslaan).

🚀 Uitbreidingsmogelijkheden

  • Best of 3 Systeem: Degene de eerste aan 3 punten is, heeft The Set gewonnen. Reset de score erna en toon een groot win-scherm.
  • Versimpelde AI: Maak een AI die onthoudt wat je de vorige keer deed, in de hoop dat menselijke spelers niet volledig random zijn!

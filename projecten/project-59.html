Project 59: Vier op een Rij

Advanced

Bouw je eigen versie van Vier op een Rij. Leer hoe je complexe winstcondities controleert in een 2D-grid met behulp van richtingsvectoren.

📚 Wat ga je leren?

Dit spel is een uitstekende introductie tot matrijs-controle in computerwetenschappen:

  • 2D Arrays (Matrices): Het speelveld modelleren in JavaScript als een 'Array van Arrays' voordat je ooit de DOM aanraakt.
  • Zwaartekracht Simuleren: Een muntje valt altijd naar de laagste mogelijke lege plek in een kolom via bottom-up iteratie.
  • Directionele Checking: In plaats van honderden IF-statements gebruiken we vectoren (delta r, delta c) om muren van verbonden fiches te tellen.

🎯 Kernconcepten

  • Data First: Wat er op het scherm gebeurt (CSS) is slechts een "weergave" van wat er in JavaScript in de grid variabele staat. JavaScript bestuurt de logica, de DOM is "dom".
  • Vectoren: Een richting als diagonaal-rechtsboven wordt in wiskunde uitgedrukt als [+1, +1] (1 rij omlaag/omhoog, 1 kolom naar rechts).
  • Cubic-Bezier Animatie: De val animatie in CSS gebruikt een specifieke transition-timing-function waardoor het perfect een versnellende, vallende steen nabootst in plaats van een lineaire verschuiving.

📝 Stap-voor-Stap Uitleg

Stap 1: Het Grid Voorbereiden

We maken een tabel via code. Een rij bevat 7 nullen, en we hebben 6 rijen.

const board = Array(6).fill().map(() => Array(7).fill(0));

Uitleg: We vullen de initiele array met `undefined`, die mappen we vervolgens naar een nieuwe array gevuld met nullen. Elke `0` betekent "Leeg". We zullen `1` voor Rood gebruiken en `2` voor Geel.

Stap 2: Muntje Gooi-Logica

Spelers klikken op een cel, wij zoeken alleen uit welke kolom ze selecteerden en zoeken het laagste vrije plekje in die kolom.

let targetRow = -1;
for (let r = ROWS - 1; r >= 0; r--) {
    if (grid[r][col] === 0) {
        targetRow = r;  // Plekje gevonden!
        break;
    }
}

Uitleg: r = ROWS - 1 start onderaan het bord (rij 5). We tellen af r-- tot rij 0 (de top). Zodra we een 0 spotten, vullen we hem met het ID van de huidige speler.

Stap 3: Winst Controle d.m.v Vector Looping

We controleren alle vier de mogelijke lijnen (Horizontaal, Verticaal, Diagonaal links/rechts) vanuit de zojuist geplaatste munt.

const directions = [

Uitleg: Door vanuit de nieuwe munt ('count=1') in twee tegenovergestelde richtingen in te kleuren en stappen te zetten, weten we in 1 keer of de reeks lang genoeg is (4 of groter).

⚠️ Veelvoorkomende Fouten

Fout: Out of bounds (Array fouten)

Tijdens het loopen om te kijken of de buurman rood/geel is, kun je per ongeluk checken of rij -1 of rij 7 bestaat. Dit geeft direct de gevreesde Cannot read properties of undefined crash. Bescherm je loops met boundary checks: nr >= 0 && nr < ROWS.

Fout: Kolom overloop

Zorg dat de handleMove functie direct retouneert (stopt) als targetRow op -1 blijft staan (wanneer the lus niks vond omdat de kolom vol zit). Anders verwijder/crash je een niet-bestaande plek in de data array.

💡 Tips voor Studenten

  • Timeout Trucjes: Omdat we CSS animaties doen, moet het muntje eerst in de DIV worden getekend bovenaan (onzichtbaar), en pas een fractie later de .coin-dropped class krijgen, anders slaat de browser de animatie per ongeluk over. Hiervoor staat er een setTimeout(() => ..., 10) in de code.

🚀 Uitbreidingsmogelijkheden

  • Slimme AI (Minimax): Voor de absolute masters: implementeer een neuraal netwerk of een minimax-algoritme dat voorspelt welke worp jou gaat laten verliezen in 3 beurten.
  • Ghost Hover: Toon een semitransparant visueel effect in de kolom waar de speler met zijn muis overheen zweeft (mouseenter event op de kolom / cel), zodat de speler kan uittekenen waar zijn fiche zal belanden.

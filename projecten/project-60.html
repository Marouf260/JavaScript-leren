Project 60: 2048 Game

Expert

Bouw de zenuwslopende 2048 puzzel. Dit project test je vermogen om met geavanceerde array manipulaties te werken, waaronder matrix rotaties en iteratieve filters.

📚 Wat ga je leren?

2048 is berucht om de complexiteit van de schuif-logica. Je leert:

  • Matrix Transpositie: Wiskundig rijen omzetten naar kolommen zodat je maar 1 'Schuif Links'-functie hoeft te schrijven voor álle vier de richtingen.
  • Datatransformatie: Hoe je een rij compact maakt (nullen weghalen), samenvoegt, en vervolgens weervult met kussens van nullen.
  • State Hashing: Controleren of het bord daadwerkelijk veranderd is na jouw actie (via JSON stringify) om te bepalen of er een nieuw blokje moet spawnen.

🎯 Kernconcepten

  • DRY Principle (Don't Repeat Yourself): Je wilt geen 4 aparte loops schrijven voor up, down, left en right. De truc is het bord draaien, altijd een 'links schuif' uitvoeren, en het weer terug draaien (Transpositie).
  • Immutable array updates: De slide() functie wijzigt de originele rij niet zomaar in-place, het creëert gepolijste iteraties met filter() en push.
  • Over-merging: Een kritiek onderdeel van 2048 is dat [2,2,4,8] na een schuif [4,4,8,0] wordt, en NIET in één klap mag samensmelten tot [16,0,0,0]. Je mag per move maar 1 merge per blokje doen!

📝 Stap-voor-Stap Uitleg

Stap 1: Schuif naar Links (De hoofdlogica)

Verwijder nullen, voeg buren samen als ze gelijk zijn, verwijder de nieuwe nullen en vul aan. Dit vormt de kern van de hele game.

function slide(row) {
    // 1. Gooi lege cellen weg
    let filtered = row.filter(x => x !== 0); 
    
    // 2. Merge gelijke buren
    for (let i = 0; i < filtered.length - 1; i++) {
        if (filtered[i] === filtered[i + 1]) {
            filtered[i] *= 2;
            filtered[i + 1] = 0;
        }
    }
    
    // 3. Gooi de nullen gemakt door de merge weg en vul weer aan tot lengte 4
    filtered = filtered.filter(x => x !== 0);
    while (filtered.length < 4) filtered.push(0);
    
    return filtered;
}

Stap 2: Matrix Draaien

We draaien het volledige 4x4 veld 90 graden mee met de klok.

function rotate(matrix) {
    return matrix[0].map((val, index) => 
        matrix.map(row => row[index]).reverse()
    );
}

Uitleg: Wil een speler naar Rechts vegen (Right)? We roteren de matrix 2x (is nu Linskom gedraaid), voeren de standaard `slide(linker)` functie uit op de datavelden, en roteren hem daarna nog 2x om op de orginele orientatie te eindigen!

Stap 3: Nieuwe Tegel Spawnen

2048 geeft 10% kans op een '4', en 90% kans op een '2', maar alleen op lege plekken.

⚠️ Veelvoorkomende Fouten

Fout: Muten van Reference Arrays

Omdat Arrays in JavaScript "by reference" (verwijzing) worden doorgegeven, moet je erg oppassen met het klonen van een matrix om te testen of het bord daadwerkelijk veranderd is door de speler. Wij gebruiken simpelweg let oldBoard = JSON.stringify(board) en checken aan het einde if (JSON.stringify(board) !== oldBoard).

Fout: Onmogelijke Game Over

Een veld zónder nullen hoeft geen Game Over te zijn! Het kan zijn dat er 0 lege plekken zijn, maar twee `16` blokjes naast elkaar liggen. Om 'Game Over' te checken, moet je naast nullen ook kijken of er nog ergens links/rechts/boven/onder een match is.

💡 Tips voor Studenten

  • Absolute Rendering: De blokjes in dit project liggen absolute gepositioneerd, maar er liggen wel donkere grid-cells "onder". Hierdoor kunnen de gekleurde getallen een vlotte transition: all 0.1s maken wanneer hun top en left positie via JavaScript geupdate wordt.

🚀 Uitbreidingsmogelijkheden

  • Swipe Besturing voor Mobiel: Omdat we nu pijtjestoetsen gebruiken via een keydown listener, is het onmogelijk om dit te spelen op je smartphone. Implementeer de touchstart/touchend of Pointer events. Bereken of de X vs Y swipe-lengte verschilt om de richting the ontcijferen.
  • Continue After 2048: Als een speler 2048 haalt is het spel technisch gewonnen. Show een dialog frame met de knoppen "Nieuw Spel" vs "Speel Door".

Project 61: Drag & Drop Kanban

Intermediate

Maak een interactief Kanban-bord (zoals Trello). Leer hoe je de native HTML5 Drag & Drop API gebruikt om elementen soepel tussen de DOM-lijsten te verplaatsen.

📚 Wat ga je leren?

Het verplaatsen van HTML-elementen die al bestaan is complexer dan velen denken. In dit project ontdek je:

  • HTML5 Drag & Drop API: De ingebouwde browser events om native dragging aan te zetten (dragstart, dragover, drop).
  • State Memory: Hoe bewaar je een interne referentie naar 'wat je aan het vasthouden bent' terwijl je muis over andere elementen zweeft?
  • DOM Node Verhuizingen: Als je appendChild() gebruikt op een element dat al ergens in het document staat, creëert dit geen duplicaat, maar knipt en plakt het de originele "Node" direct naar zijn nieuwe thuis!

🎯 Kernconcepten

  • Draggable Attribute: Zonder draggable="true" op een item (div/li), verzet de browser zich tegen elke poging om het element op te pakken (tenzij het een afbeelding of link is).
  • Event Default Prevention: Vreemd genoeg is de standaard actie van de browser om drag-and-drop te "weigeren" over specifieke gebieden. Om een drop zone aan te maken, MOET je e.preventDefault() aanroepen tijdens de `dragover`.
  • Ghosting (Visuals): Door het toevoegen van een .is-dragging class (met lagere opacity) geef je visuele feedback, terwijl de browser een native screenshot-ghost toont die de muiscursor volgt.

📝 Stap-voor-Stap Uitleg

Stap 1: Items Gereedmaken (De Bron)

Elke taak moet reageren als er aan getrokken wordt.

let draggedItem = null;

card.addEventListener('dragstart', () => {
    draggedItem = card;  // Sla het item in het geheugen op
    setTimeout(() => card.classList.add('is-dragging'), 0);
});

Uitleg: Het geheime setTimeout(..., 0) trucje zorgt ervoor dat the "Ghost" die the native API genereert het item zónder de is-dragging opacity trekt (een perfecte kopie), terwijl het originele element dat achterblijft wél vaag wordt!

Stap 2: De Kolommen Gereedmaken (Het Doel)

De lijsten moeten aangeven: "Je mag hierboven zweven en hier dingen in laten vallen."

list.addEventListener('dragover', e => {
    e.preventDefault(); // Cruciaal: Hierdoor snapt de browser dat dit een Dropzone is!
    list.classList.add('drag-over'); // Geef het een blauw stippellijntje
});

Stap 3: Het Daadwerkelijke Loslaten (Drop)

Wat gebeurt er als de muisclick wordt losgelaten boven de nieuwe kolom?

list.addEventListener('drop', () => {
    if (draggedItem) {    
        list.appendChild(draggedItem); // Verhuis de taak!
    }
});

Uitleg: appendChild is hier heel krachtig. Je trekt de taak letterlijk uit de oude `

    ` en duwt hem in de nieuwe `
      `. De DOM updatet dit direct visueel zonder dat we innerHTML magie nodig hebben.

⚠️ Veelvoorkomende Fouten

Fout: Drop Weigering (Niks gebeurt bij loslaten)

Vergeet nooit e.preventDefault() op het dragover event! Beginners missen dit vaak en worstelen uren waarom de drop listener compleet genegeerd wordt door de webkit API.

Fout: Events missen op nieuwe taken

Wanneer een gebruiker een "Nieuwe Taak" toevoegt via het formulier, móet je expliciet de dragstart en de delete eventlisteners aan die nieuwe taak binden (vandaar onze attachEvents() functie). Anders kun je nieuwe taken nooit verplaatsen.

💡 Tips voor Studenten

  • Dynamische Tellers: Merk op hoe de nummertjes (3, 1, 0) in de kolom-headers live veranderen? Dat gebeurt via de updateCounts() functie die getriggerd wordt bij elke dragend.

🚀 Uitbreidingsmogelijkheden

  • Exacte Volgorde (InsertBefore): Op dit moment valt een kaart altijd helemaal ónderaan de lijst via appendChild(). Voor de ultieme Trello-look bereken je op basis van de muis-Y positie of de kaart "tussen" twee bestaande kaarten in moet vallen met list.insertBefore().
  • Geheugen: Gebruik window.localStorage om uit te schrijven welke lijsten welke children bevatten. Zo herleeft het bord exact hoe je het achtergelaten hebt als de tab gesloten wordt.

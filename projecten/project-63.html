📚 Wat ga je leren?

De Pomodoro-techniek is wereldwijd de populairste methode voor focus. Dit project leert je de essentie van tijd-management in JavaScript:

  • Interval Intervallen: Het beheersen van setInterval() en, nog belangrijker, het stoppen daarvan via clearInterval() om "Runaway timers" the voorkomen.
  • Garderoberekening: Totaal seconden (bijv. 1500) correct terugrekenen naar minuten (25) en rest-seconden (0) via Modulo wiskunde.
  • Tab Updates: Hoe je de document.title hackt om de realtime klok te tonen in de tab van de actieve browser, the ultimate productiviteit flex!

🎯 Kernconcepten

  • Single Source of Truth: In plaats van de minuten en de seconden los bij te houden (m=25, s=0), slaan we constant The Totaal aantal seconden (1500) op. Waarom? Aftellen van 1 globale int is veel minder foutgevoelig dan het afvangen van de minuut-wissel bug (als s < 0 { m--; s=59 }).
  • Contextuele Classes op de Body: Door een class zoals .modus-rust op de <body> tag te plakken, snapt onze CSS dat niet alleen de container, maar the gehele pagina een groene uitstraling moet the krijgen.
  • String Padding: Als de timer op 5 seconden staat, vult JS standaard "5" in in plaats van "05". De functie .padStart(2, '0') is the redder in nood!

📝 Stap-voor-Stap Uitleg

Stap 1: Tijd Formatteren (De Math)

We dwingen een willekeurig getal als 1490 (seconden) in een 24:50 formaat.

function updateDisplay() {
    const mins = Math.floor(timeLeft / 60);
    const secs = timeLeft % 60; // De Modulo pakt letterlijk de "Rest" van the deelsom
    
    const timeStr = `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`;
    display.innerText = timeStr;
    document.title = `${timeStr} - Pomodoro`; // Updatet the browser tab!
}

let timerId = null;

function startTimer() {
    if (timerId) return; // Veiligheids check! Al the runnen? the Negeer de klik.
    
    timerId = setInterval(() => {
        timeLeft--;
        if (timeLeft < 0) {
            clearInterval(timerId); // Sloop The loop in het RAM geheugen
            alert('Tijd is om!');
        }
        updateDisplay();

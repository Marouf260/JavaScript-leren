📚 Wat ga je leren?

In dit project verdiepen we ons in de asynchrone natuur van het web. Je leert hoe je data ophaalt zónder de browser te blokkeren.

  • Dynamic REST APIs: Hoe je communiceert met een JSON-endpoint (DummyJSON).
  • URI Encoding: Waarom je spaties en speciale tekens moet "vertalen" voor sociale media links.
  • Conditional UI: Het tonen en verbergen van elementen (zoals loaders) op basis van de netwerkstatus.

🎯 Kernconcepten

  • Async/Await: De modernste manier om met tijdrovende processen om te gaan. Het laat code er "lineair" uitzien, terwijl het op de achtergrond wacht op de server.
  • JSON Parsing: Servers sturen tekst. .json() vertaalt die tekst naar een echt JavaScript Object waar we .quote en .author op kunnen aanroepen.
  • Tweet Intents: Gebruikmaken van Twitter's Query Parameters om een tweet voor de gebruiker klaar te zetten.

📝 Stap-voor-stap: De Twitter Koppeling

1: Het ophalen van de data

async function getQuote() {
    const response = await fetch('https://dummyjson.com/quotes/random');
    const data = await response.json();
    // Nu bevat 'data' de quote van de server
}

2: De URI Encoding (Social Deelbaar)

Sociale media links accepteren geen spaties. We gebruiken encodeURIComponent() om tekst veilig te maken voor een URL (bijv. een spatie wordt %20).

const tweetText = encodeURIComponent(`"${data.quote}" - ${data.author}`);
twitterBtn.href = `https://twitter.com/intent/tweet?text=${tweetText}`;

⚠️ Veelvoorkomende Fouten

  • DOM vergeten te verbergen: De oude quote laten staan terwijl de nieuwe laadt. Gebruik altijd container.style.display = 'none' tijdens het laden.
  • Geen Error Handling: Als de server offline is, crasht je hele script. Gebruik altijd een try...catch blok om de gebruiker te informeren.

🚀 Uitbreidingen

  • Copy to Clipboard: Voeg een knop toe die de quote kopieert met de Clipboard API.
  • Color Switcher: Verander de achtergrondkleur van de pagina op basis van de sfeer van de quote (bijv. vrolijke quotes = geel).

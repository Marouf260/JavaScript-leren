Dog API Finder

Media Fetch & States

Leer hoe je afbeeldingen asynchroon laadt van een externe API en hoe je 'Loading States' implementeert om de gebruikerservaring soepel te houden.

📚 Wat ga je leren?

Communiceren met een API gaat verder dan alleen tekst. In dit project leer je hoe je metadata (een afbeeldings-URL) verwerkt en hoe je de browser dwingt deze pas te tonen als de download écht klaar is.

  • Dynamic Image Loading: De onload event handler gebruiken om flikkering te voorkomen.
  • Async Fetch Pipeline: Het ophalen van JSON en het vertalen daarvan naar een DOM-attribuut.
  • UI State Management: Het managen van knopstatussen tijdens netwerkverkeer.

🎯 Kernconcepten

  • API Endpoint: Een specifieke URL (vandaag dog.ceo) die data terugstuurt in plaats van een webpagina.
  • The Event Loop: Begrijpen dat netwerkverzoeken tijd kosten en dat je de rest van je code niet wilt laten "bevriezen".
  • Image Buffer: Weten dat een img.src zetten het downloaden start, maar dat het onload event pas vuurt als de pixels klaar zijn.

📝 Stap-voor-stap: Geavanceerde Loading States

1: Het ophalen van de URL

const res = await fetch('https://dog.ceo/api/breeds/image/random');
const data = await res.json();
// data.message bevat nu de URL van de afbeelding

2: De Onload Trick

Veel developers maken de fout om de loader direct te stoppen na de fetch. Wij wachten tot de afbeelding zelf klaar is met laden.

img.src = data.message;
img.onload = () => {
    loader.style.display = 'none'; // Nu pas stoppen!
    img.style.display = 'block';
};

⚠️ Veelvoorkomende Fouten

  • Memory Leaks: Herhaaldelijk event listeners toevoegen binnen een loop. (Tip: definieer je onload listener één keer buiten de fetch functie).
  • Cache issues: De browser kan soms een oude afbeelding onthouden. De dog.ceo API lost dit voor ons op door unieke URL's te genereren.

🚀 Uitbreidingen

  • Breed Filter: Voeg een dropdown toe om specifieke hondenrassen op te halen (bijv. alleen Labradors).
  • Gallery Mode: Sla de laatste 5 honden op in een klein overzicht onder de hoofdafbeelding.

📚 Wat ga je leren?

GitHub biedt een van de meest gedetailleerde APIs ter wereld. In dit project leer je hoe je deze data structureert voor een eindgebruiker.

  • Dynamic Endpoint Construction: Hoe je variabelen (usernames) veilig in een URL injecteert.
  • Destructuring JSON: Het effectief uitlezen van specifieke eigenschappen uit een groot API-antwoord.
  • Form Handling: Het voorkomen van de standaard pagina-refresh bij het indienen van een zoekopdracht.

🎯 Kernconcepten

  • Template Literals: Gebruik van backticks `...` om variabelen direct in snaren te plaatsen (Interpolatie).
  • Response Handling: Controleren op response.ok. APIs sturen soms succesvol een antwoord terug om te zeggen dat ze iets niet hebben gevonden.
  • Asynchrone Functies: Gebruik van try...catch...finally voor een robuuste netwerk-logica.

📝 Stap-voor-stap: De GitHub Fetch

1: De variabelen in de URL

const username = 'octocat';
const url = `https://api.github.com/users/${username}`;
// De browser vervangt ${username} door 'octocat'

2: Foutafhandeling (De 404)

Als een gebruiker niet bestaat, stuurt GitHub een status code 404. We vangen dit op met een throw.

const response = await fetch(url);
if (!response.ok) {
    throw new Error('Gebruiker niet gevonden');
}

⚠️ Veelvoorkomende Fouten

  • API Rate Limits: GitHub staat slechts 60 verzoeken per uur toe voor niet-ingelogde gebruikers. Als je te snel klikt, krijg je een 403 error.
  • Lege Velden: Zoeken op een lege snaar. Gebruik altijd .trim() en een simpele if(username) check.

🚀 Uitbreidingen

  • Recent Repos: Haal ook de laatste 5 repositories op van de gebruiker via /repos?sort=created.
  • Dark/Light Toggle: Voeg een knop toe om het thema van de card te veranderen.

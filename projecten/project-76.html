Realtime Multi-Filtering

Bouw een geavanceerde dashboard-ervaring die communiceert met de REST Countries API. Leer hoe je grote datasets filtert op basis van meerdere criteria tegelijk.

De wereldkaart wordt uitgerold... 🌍

📚 Wat ga je leren?

In dit project werken we met datasets van meer dan 240 items. Het direct laden van complete pagina's is traag, dus we leren hoe we slim kunnen filteren in het geheugen.

  • Dynamic Array Filtering: Het tegelijkertijd filteren op tekst-input en dropdown-keuzes.
  • Intl API: Automatisch formatteren van populatiegetallen op basis van lokale conventies.
  • Lazy Loading Patterns: Hoe je efficiënt honderden afbeeldingen (vlaggen) verwerkt in de DOM.

🎯 Kernconcepten

  • Cross-Filter Logic: De "AND" logica toepassen: Een land moet én passen in de regio én passen bij de zoekterm.
  • Intl.NumberFormat: De browser-native manier om 17500000 te veranderen in 17.500.000.
  • SVG Management: Waarom SVG's superieur zijn voor vlaggen (altijd scherp, ongeacht de schaal).

2: De filter combinatie

We luisteren naar zowel 'input' (typen) als 'change' (klikken) en roepen dezelfde filterfunctie aan.

const filtered = allCountries.filter(c => {
    const nameMatch = c.name.common.toLowerCase().includes(searchInput);
    const regionMatch = region === 'all' || c.region === region;
    
    return nameMatch && regionMatch; // Beide moeten waar zijn!
});

⚠️ Veelvoorkomende Fouten

  • Case Sensitivity: Zoeken op "Nederland" werkt niet als je alles vergelijkt met "nederland". Gebruik altijd .toLowerCase() op beide kanten van de vergelijking.
  • DOM Thrashing: De grid compleet leegmaken en opnieuw bouwen bij elke toetsaanslag kan zwaar zijn. (Tip: kijk in de toekomst naar 'Virtual DOM' of 'Debouncing').

🚀 Uitbreidingen

  • Border Mapping: Toon op welke landen het huidige land grenst (via de borders array in de API).

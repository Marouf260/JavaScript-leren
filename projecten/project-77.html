📚 Wat ga je leren?

Financiële data is vluchtig. In dit project leer je hoe je een stabiele brug slaat naar een externe markt-API (CoinGecko) en hoe je deze data mensvriendelijk presenteert.

  • Periodic Fetching: Gebruik van setInterval() voor automatische achtergrond-updates.
  • Currency Localization: Getallen omzetten naar professionele Euro-notaties met het Intl object.
  • Conditional Styling: UI-elementen dynamisch kleuren (rood/groen) op basis van de marktrichting.

🎯 Kernconcepten

  • API Throttling: Waarom we niet elke seconde kunnen refreshen (Rate Limiting).
  • The Epoch & Date Object: Timestamping van data zodat de gebruiker weet hoe "vers" de informatie is.
  • toFixed() & Precision: Omgaan met zwevende getallen (floating points) in cryptocurrency prijzen.

2: De interval lus

We willen niet dat de gebruiker constant op 'refresh' hoeft te drukken. We automatiseren dit.

// 60.000 ms = 1 minuut
setInterval(() => {
    fetchPrices();
}, 60000);

⚠️ Veelvoorkomende Fouten

  • Memory Leaks: Te veel intervals starten zonder de oude te stoppen. In dit project houden we het simpel bij één actieve loop.
  • 429 Errors: De CoinGecko API is streng. Als je te vaak handmatig op verversen klikt, wordt je IP tijdelijk geblokkeerd.

🚀 Uitbreidingen

  • Historical Charts: Gebruik een bibliotheek zoals Chart.js om een kleine prijslijn van de afgelopen 7 dagen te tonen.
  • Price Alerts: Stuur een browser-notificatie als een coin boven of onder een bepaalde prijs komt.

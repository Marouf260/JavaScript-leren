OMDb API & Query Logic

Bouw een krachtige film-database app met de OMDb API. Leer hoe je zoekqueries verwerkt, omgaat met asynchrone afbeeldingen en professionele placeholders implementeert.

Filmrolletjes worden ontwikkeld... 🎬

📚 Wat ga je leren?

Het bouwen van een search engine vereist inzicht in hoe je gebruikersinput vertaalt naar een computertaal. In dit project leer je de fijne kneepjes van de OMDb API.

  • URI Encoding: Waarom je spaties in een zoekopdracht moet coderen (bijv. "Star Wars" → "Star%20Wars").
  • Placeholder Logic: Slimme fallback-scenario's bouwen voor films zonder poster.
  • Conditional UI rendering: Dynamisch reageren op 'geen resultaten' meldingen van een server.

🎯 Kernconcepten

  • API Keys & Parameters: Waarom we ?apikey=... en &s=... toevoegen aan onze URL.
  • The 'Search' Property: Begrijpen dat de OMDb API resultaten verpakt in een specifiek object genaamd Search.
  • Async Rendering: Hoe je een grid vult terwijl de afbeeldingen nog aan het downloaden zijn.

📝 Stap-voor-stap: De Zoek-Logica

1: Veilig coderen

Gebruikers typen vaak spaties of vreemde tekens. Met encodeURIComponent maken we dit veilig voor het web.

const safeTitle = encodeURIComponent(input);
const url = `https://omdbapi.com/?apikey=YOURKEY&s=${safeTitle}`;

2: De Poster Fallback

Niet elke film heeft een poster in de database. We vangen dit op met een simpele check.

const posterImg = movie.Poster !== 'N/A' 
    ? movie.Poster 
    : 'assets/placeholder.jpg';

⚠️ Veelvoorkomende Fouten

  • API Key Exposure: In dit project is de key zichtbaar in de Client-side code. In een echte productie-omgeving moet dit via een beveiligde server (Proxy).
  • Too many results: OMDb stuurt maximaal 10 resultaten per keer. Dit heet "Pagination". In dit project tonen we alleen de eerste pagina.
  • Mixed Content: OMDb draait op http://. Als je site op https:// staat, kan je browser de afbeeldingen blokkeren.

🚀 Uitbreidingen

  • Movie Details: Maak de kaarten klikbaar om extra info (plot, acteurs, IMDB rating) op te halen via de i=... parameter.
  • Watchlist: Sla je favoriete films op in de localStorage.

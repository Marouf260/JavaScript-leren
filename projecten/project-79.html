📚 Wat ga je leren?

Communicatie met een API is asynchroon. In dit project leer je hoe je deze tijd overbrugt met een visueel aantrekkelijke interface.

  • Cache Busting: Hoe je voorkomt dat de browser twee keer hetzelfde advies toont door slimme headers.
  • Interactive Feedback: De knop uitschakelen (disable) terwijl een verzoek loopt.
  • State Transitions: De UI laten 'ademen' door opacity te veranderen tijdens het laden.

🎯 Kernconcepten

  • The Fetch Options: Het tweede argument van fetch() gebruiken voor configuratie (headers, cache).
  • Finally Block: Logica die ALTIJD draait, of de fetch nu slaagt of faalt (zoals het weer inschakelen van de knop).
  • JSON Traversal: Het navigeren door de ontvangen objectstructuur: data.slip.advice.

📝 Stap-voor-stap: Het Wijsheids-Verzoek

1: Caching omzeilen

Veel APIs sturen 'static' data. Om elke keer een uniek advies te krijgen, dwingen we de browser om de cache te negeren.

const res = await fetch(url, { 
    cache: 'no-cache' 
});

2: De UI state beheren

We voorkomen dat gebruikers per ongeluk 10 keer klikken door de knop tijdelijk uit te zetten.

btn.disabled = true;
try { /* fetch */ } 
finally { btn.disabled = false; }

⚠️ Veelvoorkomende Fouten

  • The "Old Advice" Bug: De browser Onthoudt het vorige resultaat. Zonder no-cache header moet je soms 2 seconden wachten voor de API een nieuwe slip vrijgeeft.
  • Missing Try-Catch: Als het internet uitvalt, "crasht" je JavaScript. Gebruik altijd error handling bij API calls.

📚 Wat ga je leren?

Ruimtedata is overal beschikbaar. In dit project leer je hoe je geografische coördinaten van een satelliet vertaalt naar een interactieve gebruikerservaring.

  • Library Integration: Het inladen en configureren van Leaflet JS via een CDN.
  • Marker Management: Het dynamisch verplaatsen van objecten op een kaart zonder de pagina te herladen.
  • Tile Rendering: Hoe open-source kaartgegevens (OpenStreetMap) werken en hoe je ze kunt stylen.

🎯 Kernconcepten

  • Geodesie: Werken met Latitude (Breedte) en Longitude (Lengte) op een digitale bol.
  • Polling Mechanism: Waarom we setInterval() gebruiken om de seconde de nieuwe positie te 'polshanteren'.
  • Coordinate Transformation: Data van een API poort omzetten naar coördinaten op een kaartvlak.

📝 Stap-voor-stap: Het ISS Tracken

1: De Kaart Initialiseren

// L.map koppelt aan de div id 'map'
const map = L.map('map').setView([0, 0], 2);

2: De Marker Updaten

Elke keer dat de satelliet beweegt, vertellen we de kaart waar de marker heen moet.

function moveSat(lat, lon) {
    marker.setLatLng([lat, lon]);
    map.panTo([lat, lon]); // De camera volgt de marker
}

⚠️ Veelvoorkomende Fouten

  • Z-Index Issues: Kaarten kunnen soms over je dropdown-menu's vallen. We hebben dit opgelost met z-index: 1 op de map-container.
  • API Overload: Het ISS beweegt snel (28.000 km/u), maar de API houdt niet van 10 requests per seconde. Polling om de 3 seconden is perfect.

🚀 Uitbreidingen

  • Orbital Path: Gebruik L.polyline om een streep te trekken waar het ISS de afgelopen 10 minuten is geweest.
  • Day/Night Overlay: Voeg een laag toe op de kaart die laat zien waar het momenteel nacht is op aarde.

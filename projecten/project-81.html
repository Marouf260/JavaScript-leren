📚 Wat ga je leren?

De Geolocation API geeft je web-app toegang tot de GPS-hardware van het apparaat. In dit project leer je hoe je deze data veilig en visueel ontsluit.

  • Permission Handling: Hoe je omgaat met het pop-up venster van de browser (Toestaan/Weigeren).
  • Async Callbacks: Werken met success- en error-functies die op verschillende momenten kunnen vuren.
  • Live Map Integration: Dynamisch een kaart (Leaflet JS) centreren op nieuwe coördinaten.

🎯 Kernconcepten

  • The Position Object: De structuur van de data die je terugkrijgt via coords.latitude.
  • Hardware vs. IP: Waarom de locatie soms via de GPS (mobiel) en soms via de internetprovider (desktop) komt.
  • Security Policy: Waarom deze API alleen werkt via een beveiligde verbinding (HTTPS).

📝 Stap-voor-stap: De Geo-Logica

1: De Check

Niet elke browser is hetzelfde. We checken eerst of de hardware beschikbaar is.

if ('geolocation' in navigator) {
    // API is beschikbaar
}

2: De Request

We vragen de browser om de positie met twee 'callback' functies.

navigator.geolocation.getCurrentPosition(
    (pos) => { /* Success */ },
    (err) => { /* Error */ }
);

⚠️ Veelvoorkomende Fouten

  • Permission Denied: De gebruiker weigert toegang. Je app moet dit 'silent' opvangen zonder te crashen.
  • Timeout: Soms duurt het zoeken naar satellieten te lang. Je kunt in de opties een timeout meegeven.
  • Accuracy: Een gewone browser is soms meer dan 100 meter afwijkend van de werkelijkheid.

🚀 Uitbreidingen

  • WatchPosition: Gebruik watchPosition() om de coördinaten live te updaten terwijl je beweegt (bijv. wandelen).
  • Distance Calculator: Bereken de afstand tussen je huidige locatie en een ander punt (bijv. je school) via de Haversine-formule.
  • Weather Integration: Koppel de coördinaten aan een Weer-API om direct de lokale temperatuur te tonen.

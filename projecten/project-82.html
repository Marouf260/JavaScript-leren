📚 Wat ga je leren?

Moderne mobiele apparaten zitten vol sensoren. In dit project ontsluiten we de DeviceOrientation API voor interactieve 3D interfaces.

  • Spatial Data: Begrijpen van de 3 assen (Alpha, Beta, Gamma) van een apparaat in de ruimte.
  • Hardware Security: Waarom iOS en moderne Android browsers een expliciete gebruikers-actie (click) vereisen om sensoren te openen.
  • Preserving 3D: Gebruik van transform-style: preserve-3d om elementen echt diepte te geven.

🎯 Kernconcepten

  • Alpha, Beta, Gamma: De wiskundige hoeken van rotatie rond de Z, X en Y assen.
  • Gimbal Lock: Waarom sensoren soms 'in de war' raken als je het apparaat recht omhoog houdt.
  • Smoothing: Het beperken (clamping) van waarden om UI-flakkering te voorkomen.

📝 Stap-voor-stap: De Gyroscoop Logica

1: Het Permission Model

Moderne browsers vereisen toestemming. Zonder deze check blijft je code op 0 staan.

if (DeviceOrientationEvent.requestPermission) {
    const res = await DeviceOrientationEvent.requestPermission();
    if (res === 'granted') { /* Start luisteren */ }
}

2: CSS 3D Mapping

We koppelen de beta hoek aan de X-as en de gamma hoek aan de Y-as voor een tilt-effect.

card.style.transform = `rotateX(${beta}deg) rotateY(${gamma}deg)`;

⚠️ Veelvoorkomende Fouten

  • Mixing Orientations: Sommige browsers wisselen Alpha en Gamma om als je je scherm draait (Portrait vs Landscape).
  • Coordinate Overload: Sensoren vuren tot wel 60 keer per seconde. Doe geen zware berekeningen direct in de event listener.
  • HTTPS Required: Net als de Geolocation API, werkt dit NOOIT op een onbeveiligde http verbinding.

🚀 Uitbreidingen

  • Parallax Background: Beweeg de achtergrond van de pagina mee in tegengestelde richting voor een diepte-effect.
  • Shake to Reset: Gebruik de DeviceMotionEvent (versnellingsmeter) om een 'shake' te detecteren die de kaart reset.
  • Leveler App: Maak een waterpas-functionaliteit die precies 0 graden aangeeft als de tafel recht staat.

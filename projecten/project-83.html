Web Speech API (Recognition)

Bouw een live transcriptie-tool die spraak real-time omzet in tekst. Leer hoe je audiostreams beheert, talen configureert en interim-resultaten verwerkt voor een vloeiende UX.

Klaar voor opname

📚 Wat ga je leren?

De Web Speech API stelt browsers in staat om menselijke spraak te begrijpen en te vertalen naar machine-leesbare tekst.

  • Stream Processing: Hoe de browser geluidsgolven fragmenteert en analyseert.
  • Confidence Scores: Begrijpen dat de API een 'waarschijnlijkheid' teruggeeft van wat er gezegd is.
  • Continuous vs. Single: De logica achter het luisteren naar een hele presentatie versus een enkel commando.

🎯 Kernconcepten

  • webkitSpeechRecognition: De engine achter de spraakherkenning (meestal verbonden met Google of Apple servers).
  • Interim Results: Tekst die 'live' verandert terwijl de AI nog nadenkt over de context van je zin.
  • Locale (nl-NL): Belang van de juiste taalinstelling voor nauwkeurige herkenning.

📝 Stap-voor-stap: De Voice Engine

1: Initialisatie

We maken een nieuwe instance aan en vertellen de browser dat we interim (tussentijdse) resultaten willen zien.

const rec = new webkitSpeechRecognition();
rec.continuous = true;
rec.interimResults = true;
rec.lang = 'nl-NL';

2: Het Resultaat Filteren

We loopen door de resultaten en scheiden de 'definitieve' tekst van de 'tijdelijke' gissingen.

rec.onresult = (e) => {
    if (e.results[i].isFinal) {
        finalText += e.results[i][0].transcript;
    }
};

⚠️ Veelvoorkomende Fouten

  • No Internet: De meeste herkennings-engines vereisen een verbinding met de cloud om de audio te verwerken.
  • Silent Stops: Als je te lang stopt met praten, zet de browser de mic soms automatisch uit. We vangen dit op met onend logica.
  • Background Noise: De API is erg gevoelig. In een drukke ruimte zal de 'confidence score' drastisch dalen.

🚀 Uitbreidingen

  • Voice Commands: Detecteer specifieke woorden zoals "verwijder" om de tekstbox leeg te maken.
  • Auto-Download: Voeg een knop toe om de transcriptie direct als .txt bestand op te slaan.
  • Multi-Language: Maak een dropdown om te wisselen tussen Nederlands, Engels en Frans.

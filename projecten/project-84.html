Web Native Bridge

Web Share API

Ontdek hoe je de kloof overbrugt tussen web-code en de native functies van je besturingssysteem. Leer hoe je het deelmenu van je telefoon of PC direct aanspreekt zonder externe libraries.

Breek uit de Browser-Sandbox 🛠️

Moderne websites kunnen direct communiceren met het deel-systeem van je apparaat. Dit zorgt voor een naadloze ervaring die precies aanvoelt als een native app.

⚠️ Je browser ondersteunt de Web Share API niet. Gebruik een mobiele browser of Safari/Edge voor de volledige ervaring.

📚 Wat ga je leren?

De Web Share API geeft je website de kracht om data (tekst, links, bestanden) door te geven aan andere geïnstalleerde apps.

  • Feature Detection: Veilig controleren of een browser de API ondersteunt met de navigator object check.
  • Async Handling: Werken met Promises om te wachten op de keuze van de gebruiker.
  • OS Interaction: Begrijpen dat de UI verzorgd wordt door het systeem (iOS/Android/Windows), niet door je eigen CSS.

🎯 Kernconcepten

  • The Share Object: De structuur met title, text en url die je meegeeft aan de browser.
  • User Gesture: Waarom deze API alleen werkt na een expliciete klik (beveiliging tegen spam).
  • Abort Signals: Omgaan met situaties waarin een gebruiker het deelmenu opent maar vervolgens weer annuleert.

📝 Stap-voor-stap: De Deel Logica

1: De Support Check

Niet elke browser heeft deze bridge. We checken dit eerst om foutmeldingen te voorkomen.

if (navigator.share) {
    // De browser kan delen
}

2: De Async Call

We vuren het deelmenu af en wachten (await) op het resultaat.

try {
    await navigator.share({
        title: 'Mijn Awesome Web App',
        url: 'https://mijnsite.nl'
    });
} catch (err) {
    // Gebruiker annuleerde of API failure
}

⚠️ Veelvoorkomende Fouten

  • Lack of User Interaction: Als je navigator.share probeert te calls in een setTimeout of onload, zal de browser dit blokkeren.
  • Insecure Context: Deze API werkt uitsluitend op domeinen met HTTPS (of via localhost voor ontwikkeling).
  • Invalid URL: Als de url die je meegeeft niet valide is, zal de API een TypeError gooien.

🚀 Uitbreidingen

  • File Sharing: Gebruik navigator.canShare({files}) om te checken of je ook afbeeldingen of PDF's direct kunt delen.
  • Custom Fallback: Maak een eigen popup met social media icoontjes als navigator.share niet beschikbaar is.
  • Content Dynamic: Deel verschillende teksten op basis van wat de gebruiker op dat moment bekijkt op je pagina.

📚 Wat ga je leren?

De Page Visibility API stelt web-apps in staat om te weten of hun tabblad momenteel zichtbaar is voor de gebruiker.

  • State Monitoring: Het gebruik van document.hidden om de huidige focus te bepalen.
  • Resource Optimization: Het automatisch stopzetten van zware processen (zoals video of animaties) om CPU en data te besparen.
  • Context Awareness: Hoe je de beleving van de gebruiker verbetert door context-bewuste acties.

🎯 Kernconcepten

  • visibilitychange Event: Hét event dat wordt afgevuurd wanneer de gebruiker een tab switcht of de browser minimaliseert.
  • Security/Privacy: Waarom de API je wel vertelt DAT een tab verborgen is, maar NIET naar welke andere site de gebruiker is gegaan.
  • Battery Life: De enorme impact van het pauzeren van achtergrondtaken op mobiele apparaten.

📝 Stap-voor-stap: De Visibility Logica

1: Luisteren naar de Status

We voegen een global listener toe aan het document object.

document.addEventListener('visibilitychange', () => {
    // Logica hier
});

2: Actie ondernemen

Afhankelijk van de status (hidden of visible) sturen we de mediaspeler aan.

if (document.hidden) {
    video.pause();
} else {
    video.play();
}

⚠️ Veelvoorkomende Fouten

  • Autoplay Restrictions: Browsers kunnen .play() blokkeren als de gebruiker nog geen interactie heeft gehad met de pagina. Gebruik .catch().
  • Over-Engineering: Pauzeer alleen wat ECHT nodig is. Een chat-app moet bijvoorbeeld wel berichten blijven ontvangen op de achtergrond.
  • Partial Visibility: De API vertelt je alleen of het tabblad COMPLEET verborgen is. Als twee vensters naast elkaar staan, zijn beide 'visible'.

🚀 Uitbreidingen

  • Dynamic Title: Verander de document.title naar "Kom terug! 👋" als het tabblad verborgen is.
  • Ad Pausing: Pauzeer advertentie-timers zodat ze alleen lopen als ze daadwerkelijk getoond worden.
  • Dashboard Refresh: Update live grafieken minder vaak (bijv. 1x per minuut ipv per seconde) als de gebruiker niet kijkt.

Cloudless Vault

IndexedDB Storage Engine

Bouw een robuuste offline-first applicatie. Leer hoe je complexe data opslaat in een transactionele database in de browser, zonder afhankelijk te zijn van cloud-servers.

    Geen notities gevonden in de database...

📚 Wat ga je leren?

IndexedDB is een krachtige NoSQL-achtige database die lokaal in de browser draait. Het is veel krachtiger dan LocalStorage.

  • Database Schema's: Hoe je 'Object Stores' aanmaakt en beheert via onupgradeneeded.
  • Asynchronous CRUD: De vier basis-operaties (Create, Read, Update, Delete) uitvoeren via asynchrone requests.
  • Transaction Logic: Waarom databases werken met transacties om data-integriteit te garanderen.

🎯 Kernconcepten

  • Object Store: Denk aan een tabel of een 'folder' waar je JavaScript objecten direct in kunt gooien.
  • KeyPath & AutoIncrement: Hoe de database automatisch unieke ID's genereert voor je records.
  • Request Pattern: Begrijpen dat database-operaties 'requests' zijn die pas succesvol zijn in de onsuccess callback.

📝 Stap-voor-stap: De Storage Engine

1: De Database Openen

We vragen de browser om toegang. Als het schema verandert (versie 1 -> 2), vuren we een upgrade-event af.

const request = indexedDB.open('MyVault', 1);
request.onupgradeneeded = (e) => {
    const db = e.target.result;
    db.createObjectStore('notes', { keyPath: 'id', autoIncrement: true });
};

2: Een Transactie Starten

Data wegschrijven gebeurt altijd in een beveiligde transactie.

const tx = db.transaction(['notes'], 'readwrite');
const store = tx.objectStore('notes');
store.add({ text: 'Hallo Wereld' });

⚠️ Veelvoorkomende Fouten

  • Version Mismatch: Als je het schema verandert maar de versie-nummmer niet ophoogt, zal onupgradeneeded niet vuren.
  • Quota Exceeded: Browsers hebben een limiet (vaak % van de schijfruimte). Bij extreem grote data-sets kan een QuotaExceededError optreden.
  • Closed Transactions: Een transactie sluit zich automatisch zodra er geen werk meer is. Je kunt hem niet 'heropenen'; je moet een nieuwe maken.

🚀 Uitbreidingen

  • Full Text Search: Gebruik IDBKeyRange om te kunnen zoeken in je notities op basis van tekst.
  • Categories/Tags: Voeg een extra veld toe aan je objecten zodat je notities kunt filteren op kleur of type.
  • Export to JSON: Maak een functie die je hele database uitleest en downloadt als een backup-bestand.

Clipboard Bridge API

Maak een naadloze verbinding tussen je web-app en de rest van het besturingssysteem. Leer hoe je data asynchroon leest en schrijft naar het systeemklembord met volledige permissie-controle.

Brontekst

🚀 De moderne Clipboard API biedt een veilige, op Promises gebaseerde manier om interactie te hebben met het klembord. Geen onhandige 'document.execCommand' meer nodig!

Gekopieerd naar klembord! ✅

📚 Wat ga je leren?

Het klembord is een gedeelde resource op het systeem. De browser beschermt dit streng tegen misbruik.

  • Async Handling: Het werken met de navigator.clipboard interface die Promises retourneert.
  • Permission Management: Begrijpen waarom 'lezen' (paste) vaak een expliciete browser-popup voor toestemming vereist.
  • UX Feedback: Het implementeren van 'toasts' of status-updates om de gebruiker te laten weten dat een actie is geslaagd.

🎯 Kernconcepten

  • writeText(): De methode om tekst naar het klembord te sturen. Dit werkt alleen in een 'secure context' (HTTPS).
  • readText(): De methode om de huidige klembord-inhoud op te vragen.
  • User Gesture: Waarom deze API alleen werkt naar aanleiding van een klik-event (beveiliging tegen data-diefstal).

📝 Stap-voor-stap: De Clipboard Logica

1: Schrijven (Kopiëren)

We vuren de tekst af en wachten tot de browser bevestigt dat het op het klembord staat.

async function doCopy(text) {
    await navigator.clipboard.writeText(text);
    // Toon feedback
}

2: Lezen (Plakken)

We vragen de inhoud op. Let op: dit kan een permission-prompt triggeren!

const clipped = await navigator.clipboard.readText();
targetArea.value = clipped;

⚠️ Veelvoorkomende Fouten

  • Calling from Background: De Clipboard API werkt vaak niet als de pagina niet gefocust is (visibility check).
  • Insecure Context: Net als Geolocation werkt dit op echte domeinen alleen via HTTPS. Localhost is een uitzondering voor dev.
  • Large Data: Voor afbeeldingen of rich text moet je navigator.clipboard.write([items]) gebruiken ipv writeText().

🚀 Uitbreidingen

  • Rich Text Support: Experimenteer met het kopiëren van HTML zodat opmaak (vet, cursief) behouden blijft in Word/Pages.
  • History Manager: Bouw een app die je eigen klembord-historie bijhoudt binnen de sessie.
  • Auto-Format: Strip automatisch ongewenste karakters of links uit tekst die de gebruiker in je app plakt.

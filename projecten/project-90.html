📚 Wat ga je leren?

Moderne browsers fungeren als een bridge naar de fysieke hardware van je telefoon of laptop.

  • Haptics: Het gebruik van patronen (arrays van aan/uit milliseconden) voor vibratie.
  • Energy Awareness: Hoe je web-apps 'zuinig' maakt door features uit te schakelen bij een lage batterij.
  • Event Listeners: Reageren op hardware-veranderingen (zoals het aansluiten van een oplader).

🎯 Kernconcepten

  • Vibration Pattern: Een array zoals [100, 50, 100] betekent: 100ms trillen, 50ms stilte, 100ms trillen.
  • Battery Manager: Een asynchroon object met properties als level, charging, dischargingTime.
  • Hardware Restrictions: Waarom iOS (Apple) bepaalde APIs zoals vibratie blokkeert in de browser.

📝 Stap-voor-stap: De Hardware Logic

1: Trillen met Patronen

Simpel of complex, jij bepaalt het ritme.

// 200ms trillen
navigator.vibrate(200);

// SOS: kort-kort-kort, lang-lang-lang...
navigator.vibrate([100,100,100, 300,100,300]);

2: De Batterij Uitlezen

We vragen toegang en luisteren naar updates.

const bat = await navigator.getBattery();
bat.addEventListener('levelchange', () => {
    console.log(bat.level * 100 + '%');
});

⚠️ Veelvoorkomende Fouten

  • Silent/DND Mode: Als een telefoon op 'Niet Storen' staat, negeert de hardware vaak de vibrate commando's.
  • Permission Denial: Hoewel Batterij API vaak geen popup geeft, moet de site wel op de voorgrond staan.
  • Legacy Support: De Battery API is in sommige hele oude browsers (of juist hele nieuwe Firefox versies) soms verwijderd wegens privacy.

🚀 Uitbreidingen

  • Game Feedback: Laat de telefoon trillen wanneer de speler in een game een muntje pakt of geraakt wordt.
  • Energy Saver Mode: Verlaag de frame-rate van je animaties automatisch zodra de batterij onder de 15% komt.
  • Charging Notification: Speel een sound effect of toon een felicitatie-animatie zodra de gebruiker zijn toestel in de lader steekt.

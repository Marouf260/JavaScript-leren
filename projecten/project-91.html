📚 Wat ga je leren?

Bij dit project duiken we diep in real-time string manipulatie en asynchrone timers.

  • Array Analysis: Hoe je een string splitst in individuele spans voor pixel-perfecte feedback.
  • WPM Algoritme: De industriestandaard berekening voor typ-snelheid.
  • State Syncing: Het synchroniseren van user-input met een visuele template.

🎯 Kernconcepten

  • Input Event: Waarom we 'input' gebruiken in plaats van 'keydown' voor tekstverwerking.
  • Zero-Index Targeting: Het bijhouden van de charIndex om de actieve letter te markeren.
  • Precision Counting: Het onderscheid tussen bruto aanslagen en netto correcte woorden.

📝 Stap-voor-stap: De Kernlogica

1: Tekst Tokenizeren

We veranderen de zin in een reeks <span> elementen zodat we elke letter apart kunnen kleuren.

// Voorbeeld van rendering
text.split("").forEach(char => {
    let span = `<span>${char}</span>`;
    container.innerHTML += span;
});

2: De WPM Formule

WPM wordt berekend door het aantal karakters te delen door 5 (het gemiddelde woord) en dit te schalen naar een minuut.

let wpm = Math.round(((charIndex - errors) / 5) / (timePassed / 60));

⚠️ Veelvoorkomende Fouten

  • Space-bar skipping: Het vergeten van de spatie als een geldig karakter in je indexering.
  • Timer Drift: setInterval kan soms licht afwijken; voor absolute precisie gebruik je Performance.now().
  • Focus Loss: Als de gebruiker buiten het invoerveld klikt, stopt de invoer maar de timer loopt vaak door.

🚀 Uitbreidingen

  • Difficulty Modes: Voeg zinnen toe met speciale tekens of programmeercode voor professionals.
  • Geluidsfeedback: Voeg een subtiel tik-geluid toe bij elke aanslag en een 'fout' geluid bij missers.
  • Dashboard: Sla je highscores op in localStorage om je voortgang over tijd te zien.

Graphics & Pixel Rendering

Creëer kunst met code. Leer hoe je de HTML5 Canvas API gebruikt om paden te tekenen, kleuren te mengen en meesterwerken te exporteren.

📚 Wat ga je leren?

De HTML5 Canvas API is de basis voor games, grafieken en fotobewerkers in de browser.

  • 2D Context: Het begrijpen van de getContext('2d') interface.
  • Coordinate System: Hoe de X- en Y-as werken vanaf de linkerbovenhoek.
  • Dynamic Drawing: Het koppelen van muisbewegingen aan lineTo() commando's.

🎯 Kernconcepten

  • Path State: Beginnen met beginPath() is cruciaal om te voorkomen dat oude lijnen meekleuren.
  • Line Caps: Gebruik lineCap = 'round' voor vloeiende, ronde lijnen zonder hoekjes.
  • Offset Calculation: Corrigeren voor de positie van het canvas op de pagina met getBoundingClientRect().

📝 Stap-voor-stap: Tekenen met JS

1: De Muis Volgen

We hebben drie events nodig: mousedown (start), mousemove (teken) en mouseup (stop).

function draw(e) {
    if (!isDrawing) return;
    ctx.lineWidth = size;
    ctx.lineTo(e.offsetX, e.offsetY);
    ctx.stroke();
}

2: Exporteren

Het canvas kan zichzelf omzetten naar een Base64 string die als afbeelding gedownload kan worden.

const dataURL = canvas.toDataURL('image/png');

⚠️ Veelvoorkomende Fouten

  • Wazige Lijnen: Dit gebeurt vaak als de CSS-grootte van het canvas verschilt van de HTML-attributen width/height.
  • Muis buiten Canvas: Als de gebruiker de muisknop loslaat buiten het canvas, kan isDrawing 'true' blijven. Gebruik een globale window listener voor 'mouseup'.
  • Mobile Touch: mousemove werkt niet op mobiel. Je moet touchstart en touchmove events toevoegen.

🚀 Uitbreidingen

  • Shape Tools: Voeg knoppen toe om perfecte cirkels of rechthoeken te tekenen.
  • Undo/Redo: Gebruik een array om de 'state' van het canvas op te slaan na elke actie.
  • Filter Effecten: Gebruik ctx.filter om effecten zoals blur of sepia toe te voegen aan je tekening.

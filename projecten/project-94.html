Web Audio API & Sound Synthesis

Verander je browser in een synthesizer. Leer hoe je geluidsgolven genereert, oscillators aanstuurt en ADSR-envelopes gebruikt.

Gebruik je toetsenbord (A tot K) of klik/tap om te spelen.

📚 Wat ga je leren?

De Web Audio API is een modulair systeem waarmee we geluid kunnen 'patchen' als bij een echte modulaire synthesizer.

  • Oscillators: De generator van de basis-golfvorm.
  • Audio Context: De motor die alle audio-berekeningen in de browser aanstuurt.
  • Gain Nodes: De volumeregeling die we dynamisch aanpassen via code.

🎯 Kernconcepten

  • User Gesture Requirement: Browsers blokkeren audio tot de gebruiker interactie heeft (klikken).
  • Frequency Math: Elke noot (zoals A4 = 440Hz) heeft een specifieke trillingsfrequentie.
  • Ramping: Het vloeiend laten eindigen van geluid om 'klikjes' te voorkomen (ADSR basic).

📝 Stap-voor-stap: Sound Logic

1: Oscilator Initialiseren

We maken voor elke noot een tijdelijke oscillator aan.

const osc = audioCtx.createOscillator();
osc.type = 'sawtooth';
osc.frequency.value = 440; // A4

2: De Signal Chain

We verbinden de oscillator met een gain node (volume) en daarna met de speakers.

osc.connect(gainNode);
gainNode.connect(audioCtx.destination);

⚠️ Veelvoorkomende Fouten

  • InvalidStateError: Dit gebeurt als je probeert een gestopte oscillator opnieuw te starten. Oscillators zijn 'single-use'.
  • Audio Clipping: Als je het volume boven 1.0 zet, gaat het geluid vervormen (kraken).
  • Latency: Te veel actieve nodes tegelijkertijd kunnen voor vertraging of haperingen zorgen.

🚀 Uitbreidingen

  • Recording Mode: Neem je piano-sessie op en exporteer deze als .wav bestand.
  • Effects Pedal: Voeg een DelayNode of BiquadFilterNode toe voor echo en reverb effecten.
  • Visualizer: Gebruik een AnalyserNode om de geluidsgolven visueel te maken op een canvas.

📚 Wat ga je leren?

Breakout is de ideale oefening voor het begrijpen van tweedimensionale beweging.

  • Entity Management: Het bijhouden van paddles, ballen en stenen als objecten.
  • Collision Detection: Berekenen wanneer polygonen elkaar overlappen.
  • Drawing States: Het canvas elke frame wissen en opnieuw tekenen.

🎯 Kernconcepten

  • requestAnimationFrame: Waarom dit beter is dan setInterval voor games (syncen met de schermverversing).
  • Velocity Vectors: Hoe dx en dy de richting en snelheid van de bal bepalen.
  • Loop Filtering: Efficiënt controleren welke stenen nog 'alive' zijn in de array.

📝 Stap-voor-stap: De Game Loop

1: Botsing met Muren

Als de bal de rand raakt, draaien we de snelheid om.

if (x + dx > canvas.width - ballRadius || x + dx < ballRadius) {
    dx = -dx; // Draai X-richting om
}

2: Baksteen Detectie

We itereren door de 2D-array van stenen bij elke frame.

if (ballX > b.x && ballX < b.x + bWidth && ballY > b.y && ballY < b.y + bHeight) {
    dy = -dy;
    b.status = 0; // Steen is kapot
}

⚠️ Veelvoorkomende Fouten

  • Sticky Paddle: De bal die 'vastplakt' aan de paddle doordat de dy meerdere keren wordt omgedraaid in één frame.
  • Canvas Clipping: Vergeten de paden te sluiten (closePath()), wat zorgt voor vreemde lijnen.
  • Frame Skipping: Hard-coded snelheden die anders aanvoelen op een 144Hz scherm vergeleken met 60Hz.

🚀 Uitbreidingen

  • Power-ups: Vallende items die je paddle groter maken of de bal vertragen.
  • Levels: Maak een reeks lay-outs die steeds moeilijker worden met verschillende kleuren stenen.
  • Particle Effects: Teken kleine vonkjes op het canvas wanneer een steen geraakt wordt.

Studio Code Pro Gids

📚 Wat ga je leren?

Je bouwt een mini "CodePen" of "JSFiddle". Dit leert je alles over geavanceerde DOM manipulatie en zandbak omgevingen.

  • External Libraries: Hoe je CodeMirror integreert voor syntax highlighting.
  • Safe Execution: Het injecteren van code in een iframe om de hoofdpagina te beschermen.
  • Editor Refreshes: Het synchroon houden van meerdere documenten (HTML, CSS, JS).

🎯 Kernconcepten

  • Iframe Document: Toegang krijgen tot de body van een frame via iframe.contentDocument.
  • State Management: Het opslaan van broncodes in een centraal object.
  • BLOB URLs: (Uitbreiding) Hoe je bestanden kunt genereren zonder server.

📝 Stap-voor-stap: De Preview Engine

De kern van een live editor is het dynamisch herschrijven van de frame content.

const doc = iframe.contentDocument;
doc.open();
doc.write(html + `<style>${css}</style>`);
doc.write(`<script>${js}</script>`);
doc.close();

🚀 Uitbreidingen

  • Auto-Save: Sla de code op in localStorage zodat je werk niet verloren gaat bij een refresh.
  • Console Emulator: Maak een extra paneel dat console.log berichten uit het iframe opvangt.
  • Multi-Theme: Laat de gebruiker wisselen tussen Dracula, Monokai of Light thema's.

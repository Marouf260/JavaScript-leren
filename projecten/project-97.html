Markdown Writer Gids

📚 Wat ga je leren?

Je bouwt een krachtige tekstverwerker die Markdown-tekst in real-time omzet naar HTML.

  • Regex Parsing: Patronen herkennen zoals `#` voor titels en `**` voor dikgedrukte tekst.
  • Text Ingestion: Hoe je input-events gebruikt voor onmiddellijke feedback.
  • Blob & File API: Browser-tekst exporteren als downloadbare bestanden.

🎯 Kernconcepten

  • String replacement: Gebruik van `.replace()` met globale flags (`/g`).
  • Markdown Syntax: Begrijpen hoe symbolen worden vertaald naar HTML tags.
  • DOM Sanitization: Waarom we voorzichtig moeten zijn met het injecteren van pure HTML.

📝 Stap-voor-stap: De Parser

We gebruiken reguliere expressies om patronen te vangen.

function parseMarkdown(text) {
  return text
    .replace(/^# (.*$)/gim, '<h1>$1</h1>')
    .replace(/\*\*(.*)\*\*/gim, '<b>$1</b>');
}

🚀 Uitbreidingen

  • Syntax Highlighting: Voeg een bibliotheek als Prism.js toe voor code-blokken.
  • Word Counter: Toon live het aantal woorden en karakters onderaan de editor.
  • Dark/Light Mode: Laat de gebruiker het kleurenschema aanpassen.

📚 Wat ga je leren?

Het video element in HTML is extreem krachtig maar vaak lelijk. Je leert hoe je 'onder de motorkap' kijkt.

  • Media State: Controleren of video gepauzeerd is via video.paused.
  • Event Orchestration: Reageren op timeupdate om de progressbar te animeren.
  • Fullscreen API: Het correct aanvragen van browser-brede weergave.

🎯 Kernconcepten

  • Metadata: Hoe je de totale duur (duration) ophaalt zodra de video geladen is.
  • Seeking: De currentTime property aanpassen om vooruit of achteruit te spoelen.
  • Calculated Progress: Math gebruiken om de percentage-breedte van de voortgangsbalk te bepalen.

📝 Stap-voor-stap: Progress Logic

// Bereken voortgang
const percent = (video.currentTime / video.duration) * 100;
progressBar.style.width = `\${percent}%`;
